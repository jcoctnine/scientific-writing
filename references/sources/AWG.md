## 方法卡

以下 44 条按原书组织。操作化动作是对原书方法的整理，不等同于作者逐字规定；原提取稿中待审阅的技能建议字段未转入本文件，实际执行规则见方法簇。

<a id="awg-001"></a>

### AWG-001 先按读者与任务确定信息量

**原书方法**：写作中的读者、目的、组织、风格、信息流和呈现相互关联；读者对主题的熟悉程度影响背景、定义和细节的取舍。

**适用情境**：起草前定位，或修改背景过多、术语解释不足的稿件。

**操作步骤**：整理者操作化：明确目标读者及其已知内容；说明本文要解决的读者问题；据此保留必要背景，删除与阅读目的无关的说明。

**限制与例外**：书中有课程作业情境；“向教师展示知识”不能直接变成期刊论文的目的，也不能假定所有同行具有相同背景。

**来源**：Unit 1 / Audience; Purpose and Strategy；书内 pp. 3–8；PDF 第 13–18 页。

<a id="awg-002"></a>

### AWG-002 以领域实例辨认风格，而非套用禁令

**原书方法**：学术风格存在学科和体裁差异；第一人称、缩写、直接提问、主动或被动等是修辞选择。原书建议分析本领域写得好的研究论文，并可借助语料观察惯用表达。

**适用情境**：选择语态、人称、措辞或为以后期刊／研究者风格定制建立依据。

**操作步骤**：整理者操作化：从已提供且体裁相符的论文记录组织、句法及表达实例；辨认这些表达服务的目的；只采用适合当前内容的惯例。

**限制与例外**：不能把语料频率当成必须遵守的规则，不能把书评／讲课风格套到原创论文。书中 2011–2012 年搜索数量、网站功能和频率不是当前事实。

**来源**：Unit 1 / Style; Language Focus; Using Google Scholar；书内 pp. 14–30；PDF 第 24–40 页。

<a id="awg-003"></a>

### AWG-003 用旧信息连接新信息

**原书方法**：句首或主语位置承接已知内容，句尾引入新内容；下一句可承接上一句的开头或结尾。重复关键词、同义表达及语态选择均可维护信息流。

**适用情境**：段落句子各自正确但连接生硬，或过度依赖 however 等连接词。

**操作步骤**：整理者操作化：标出每句已知和新信息；检查相邻句是否有内容桥梁；调整主语或主动／被动选择；无法自然衔接时，再用明确关系的连接语。

**限制与例外**：不是每句都必须机械重复前句词语；原书明确允许用逻辑连接词处理无法方便维持旧→新顺序的情形。不能为主动语态而破坏信息流。

**来源**：Unit 1 / Flow; Old-to-New Information Flow；书内 pp. 30–36；PDF 第 40–46 页。

<a id="awg-004"></a>

### AWG-004 让连接词与回指表达承担准确的关系

**原书方法**：连接语要对应增补、转折、因果、对照等真实关系；this/these + 概括名词既可澄清回指，也会表达作者对前文的解释。

**适用情境**：代词指向不明，或连接词掩盖内容断裂的段落。

**操作步骤**：整理者操作化：先判断前后关系，再选择连接表达；定位 this/these 指代范围；有歧义时补入准确概括名词；检查该名词是否暗加了评价。

**限制与例外**：原书承认 unattended this 在部分动词前常见且合理，不是所有 this 后都必须加名词；概括短语过长也可能降低清晰度。标点需与句法及期刊格式相符。

**来源**：Unit 1 / Linking Words and Phrases; This and Summary Phrases；书内 pp. 37–48；PDF 第 47–58 页。

<a id="awg-005"></a>

### AWG-005 按内容、信息流、语言和呈现修订

**原书方法**：原书建议先处理内容与信息流，再检查语法、拼写及格式；自动语法检查器的建议可能破坏句间连接，不能机械接受。

**适用情境**：已有稿件的多层次修订和最后校对。

**操作步骤**：依据原书顺序整理：先检查论述与内容桥梁；再检查段落和适用格式；再查时态、主谓、冠词等；最后检查拼写与同音词，并复查信息流。

**限制与例外**：具体语法细则和排版规范依学科／期刊而异；文字校对不证明研究证据或统计分析正确。

**来源**：Unit 1 / Presentation；书内 pp. 48–52；PDF 第 58–62 页。

<a id="awg-006"></a>

### AWG-006 按论述需要选择一般→具体或具体→一般

**原书方法**：GS 结构从一般命题逐步缩小到细节，末句有时再扩大；SG 可从个案、事件或具体证据引向较大的问题，尤其见于历史、艺术和某些医学体裁。

**适用情境**：背景、引言开头、概念介绍和具体案例引出的研究问题。

**操作步骤**：整理者操作化：先确定段落终点；为 GS 逐句收窄范围，为 SG 说明细节与大问题的关系；选用一般陈述、适切统计或定义作为开头。

**限制与例外**：开头需考虑读者能否理解；不能规定所有论文都从宏大背景开始。具体案例不能未经论证代表总体；SG 在书中有明显学科／体裁条件。

**来源**：Unit 2 / General-Specific and Specific-General Texts; Opening; Specific-to-General Organization；书内 pp. 55–65; 92–99；PDF 第 65–66、69–75、102–109 页。

<a id="awg-007"></a>

### AWG-007 按定义的必要性和歧义程度控制解释深度

**原书方法**：陌生术语、意思有分歧或需要厘清的概念可定义。定义可为短注、单句或扩展说明；正式单句定义通常给出上位类别及区别性特征。

**适用情境**：专业术语、新方法、读者可能混淆的变量或关键概念。

**操作步骤**：整理者操作化：检查读者是否需要定义；选择短注／单句／扩展形式；说明所属类别及区分特征；必要时补组成、作用机制、应用或例子。

**限制与例外**：定义的长度取决于目的、读者知识及共识程度；避免循环定义，但原书承认适当重复术语有时有利于清晰。不能用扩展定义堆积与论文无关的百科知识。

**来源**：Unit 2 / Opening with Definitions; Writing a Definition; Extended Definitions；书内 pp. 65–78；PDF 第 75–88 页。

<a id="awg-008"></a>

### AWG-008 对照定义要说明共同基础、差异与采用的边界

**原书方法**：两个相关概念不宜只独立定义，还应指出它们的共同类别和区别。遇到竞争定义，应交代分歧并明确本文采用哪一种；不同学派可按共同问题比较。

**适用情境**：相关概念辨析、操作定义、理论框架和研究之间的可比性说明。

**操作步骤**：整理者操作化：列出共同基础及区分维度；按相同维度对照；有多种定义时说明本文采用的定义及适用范围，并保留相应来源。

**限制与例外**：并非所有术语都有争议；不能为显示新颖而虚构争议。书中对不同定义／学派的介绍不是要求所有文章写独立理论综述。

**来源**：Unit 2 / Definitions to Demonstrate a Distinction; Variations in Definitions; Discussions of Schools of Thought；书内 pp. 82–91；PDF 第 92–101 页。

<a id="awg-009"></a>

### AWG-009 用情境—问题—解决—评价组织论证

**原书方法**：问题—解决结构不仅描述内容，还需让读者相信问题成立、解决办法合理；典型功能是情境、问题、解决、评价，部分解决可引出新问题和新一轮解决。

**适用情境**：引言中的现实问题、方法必要性或解释某一研究方案。

**操作步骤**：整理者操作化：交代必要情境；以证据界定问题；说明解决路径；评价有效范围及局限；若方案只解决部分问题，明确剩余问题。

**限制与例外**：四个功能不等于四个段落；可存在重复循环，也不要求每篇论文都采取 PS。不能将课堂“发挥想象”的练习要求用于真实研究事实。

**来源**：Unit 3 / The Structure of Problem-Solution Texts; Procedures and Processes; Introducing the Solution；书内 pp. 100–108; 137–138；PDF 第 110–114、116–118、149–150 页。

<a id="awg-010"></a>

### AWG-010 根据过程焦点选择语态

**原书方法**：过程说明通常以过程对象和阶段为中心，被动语态可维持这种焦点；自然过程、状态改变以及需要突出动作主体的场景可用主动语态或混合语态。

**适用情境**：Methods、系统流程及机制过程的文字说明。

**操作步骤**：整理者操作化：区分说明过程与下达操作指令；确定每一步的焦点；据此选择主语和语态；动作主体影响理解时保留主体信息。

**限制与例外**：不是 Methods 必须全被动，也不是主动一定更清楚。原书区分以祈使句指导操作和说明过程；自然过程常用主动。

**来源**：Unit 3 / Passive Voice; Active Voice in Process Descriptions；书内 pp. 119–123; 129–132；PDF 第 129–133、141–144 页。

<a id="awg-011"></a>

### AWG-011 写清步骤顺序，同时消除修饰范围歧义

**原书方法**：时序表达、并列动词、过去分词形容词可连接步骤并追踪处理后的对象；但并列动词共享时长、容器或工具说明时可能产生歧义。

**适用情境**：Methods 中顺序不明、重复冗长或修饰范围不清的操作描述。

**操作步骤**：整理者操作化：列出实际步骤顺序；标明先后／并行关系；适度合并同一对象的动作；逐项确认时间、方式和位置究竟修饰哪一步。

**限制与例外**：不要为省字把不同时长或不同条件的动作合并；分词承接必须符合对象实际状态。只有作者提供了条件才能补写，不能凭常见实验流程补事实。

**来源**：Unit 3 / Flow of Ideas in a Process Description; Participles；书内 pp. 125–129；PDF 第 137–141 页。

<a id="awg-012"></a>

### AWG-012 分别表达因果、目的与尚待回答的问题

**原书方法**：原书介绍因果动词、连接词及 -ing 结果从句，并用间接疑问表达研究目的和待解问题；引入方案可采用多种表达，需装入自己的研究内容。

**适用情境**：问题解释、研究目的、方法理由以及方案到预期作用的连接。

**操作步骤**：整理者操作化：区分已发生的结果、目的和待验证问题；为每种关系选对应句式；用间接疑问表达尚不确定的关系；避免把目的句改写成已实现效果。

**限制与例外**：语法形式不提供因果证据。原书允许某些直接问题，不要求一律改为间接问题；通用骨架可借用，整句原创观点不能当作模板移用。

**来源**：Unit 3 / -ing Clauses to Indicate Cause and Effect; Indirect Questions; Introducing the Solution；书内 pp. 115–118; 133–138；PDF 第 125–128、145–150 页。

<a id="awg-013"></a>

### AWG-013 让数据评论承担定位、重点和解释功能

**原书方法**：数据评论通常先给图表位置／总体概述，再突出关键发现，最后视需要讨论含义、问题、例外或建议；指向图表的句子可仅说明内容，也可传递主要发现。

**适用情境**：Results 或其他章节中图表附近的文字。

**操作步骤**：整理者操作化：明确图表支持的论点；选一般定位或信息性定位；补关键趋势；按该章节允许的范围解释与限定。

**限制与例外**：原书说明评论长度随体裁变化，期刊中可短至一句；不能把三种功能固定为三段。图表指向的语态应服务信息流而非刻意交替。

**来源**：Unit 4 / Structure of Data Commentary; Location Elements and Summaries; Linking as Clauses；书内 pp. 139–141; 144–155；PDF 第 151–153、156–167 页。

<a id="awg-014"></a>

### AWG-014 提炼数据支持的重点，不逐项复述

**原书方法**：highlighting statements 应发现趋势、区分重要与次要信息，并以恰当强度概括；既要避免逐个数字复述，也要避免读出数据并不支持的结论。

**适用情境**：Results 文字像数字清单，或结论超出表中证据。

**操作步骤**：整理者操作化：按研究问题确定最重要比较；指出可直接支持的规律；保留解释所需的关键数值／例外；核对句子与实际数据一致。

**限制与例外**：选择重点不等于删除反例或不利结果；单纯漂亮叙述不替代数据支持。原书没有授权按预期结论选择数据。

**来源**：Unit 4 / Strength of Claim; Highlighting Statements；书内 pp. 139–140; 156；PDF 第 151–152、168 页。

<a id="awg-015"></a>

### AWG-015 按证据校准主张强度，避免过强或过度含糊

**原书方法**：可通过可能性、与来源的距离、限定主体／范围、加入例外和较弱动词调节断言；多个限定可组合，但过度叠加会使句子几乎不表达内容。

**适用情境**：因果断言、总体概括和 Discussion 解释。

**操作步骤**：整理者操作化：判断证据支持何种范围及确定程度；优先给实质范围限定；再选匹配强度的动词或情态表达；删掉重复而无信息的缓和语。

**限制与例外**：不是所有句子都要加 may；不能用 hedging 掩盖无证据推测。各种表达的相对强弱须结合上下文，不能当作量化概率标尺。

**来源**：Unit 4 / Qualifications and Strength of Claim; Specific Ways of Moderating or Qualifying a Claim；书内 pp. 156–164；PDF 第 168–176 页。

<a id="awg-016"></a>

### AWG-016 比较句要保留比较对象与幅度

**原书方法**：比较语言能比逐列数字更有效地呈现差异，但 more/fewer 等过于模糊时应给出幅度；复杂比较需明确两侧比较的是同一种量。

**适用情境**：组间差异、方法性能、比例、倍数及变化幅度的写作。

**操作步骤**：整理者操作化：明确比较量、对象和参照；在需要时写出差值或比值；核对限定词、单位与分母；确保 that/those 没有指错比较量。

**限制与例外**：书内 p.168 将 64% 与 56% 的差写成 eight percent，且有 times higher 等可能含混的教学表达；不照抄这些数量表述。百分比与百分点、比值与增加倍数的核对属于整理者补充的准确性要求。

**来源**：Unit 4 / Organization; Comparisons; Unit 7 / Making Comparisons；书内 pp. 165–169; 316–319；PDF 第 177–181、328–331 页。

<a id="awg-017"></a>

### AWG-017 异常和不完美数据应被讨论

**原书方法**：出现异常、预期与实际不一致或已知限制时，通常应说明，而非忽略；可给出有依据且适度限定的解释，并提出能解决该问题的后续工作。

**适用情境**：不显著、方向相反、测量异常或代表性有限的结果。

**操作步骤**：整理者操作化：准确指出异常是什么；区分观察事实和候选解释；说明解释依据及其不确定性；必要时指出可检验的后续研究。

**限制与例外**：原书中的小样本、仪器缺陷等是示例原因，不是可自动套用的诊断；不得编造失败原因。后续研究仅在适用时加入。

**来源**：Unit 4 / Concluding a Commentary; Dealing with Unexpected Outcomes or Problems；书内 pp. 172–176；PDF 第 184–188 页。

<a id="awg-018"></a>

### AWG-018 时间数据兼顾总趋势与时间顺序

**原书方法**：图形评论沿用数据评论原则，但学科图形术语有差异；时间数据通常可以把总体概括与按时序展开结合起来。

**适用情境**：纵向变化、实验时程或曲线之间的比较。

**操作步骤**：整理者操作化：先概括主要模式；再按关键阶段描述转折、峰值、稳定段或组间差异；标明必要时间范围；最后写与问题有关的意义。

**限制与例外**：不必报告每个时点；“峰值”“线性”等需图或数据支持。曲线示例不能被当成科学事实或直接搬入用户论文。

**来源**：Unit 4 / Dealing with Graphs; Dealing with Chronological Data；书内 pp. 177–183；PDF 第 189–195 页。

<a id="awg-019"></a>

### AWG-019 围绕当前论点做忠实摘要

**原书方法**：有效摘要应与当前用途相关、准确表现来源，并以自己的语言压缩。原书建议先看结构、阅读全文和记笔记，再逐段概括、保留关键支持及原有主张强度。

**适用情境**：把既有文献嵌入引言、背景或 Discussion。

**操作步骤**：依据原书整理：辨识来源体裁和结构；阅读相关全文；记录与目的相关的核心点和支持；保留结论力度；把自己的反应与来源内容分开；需要时重读核验。

**限制与例外**：摘要长度取决于目的；来源支持自己的解释，但不应替代解释。选择相关内容不能歪曲来源或隐去改变结论的限定。

**来源**：Unit 5 / Considerations before Writing a Summary；书内 pp. 188–190；PDF 第 200–202 页。

<a id="awg-020"></a>

### AWG-020 从理解和关系重组进行释义

**原书方法**：好的释义重述原意；先识别重要命题和彼此关系，再重新组织。逐句换同义词可能搭配不自然、歪曲含义，且不能充分体现理解。

**适用情境**：已有文献段落需要用自己的话说明。

**操作步骤**：依据原书整理：拆分重要命题与因果／对照等关系；放下原文后按理解重写；核对原意、细节与强度；检查搭配；保留必要技术术语。

**限制与例外**：不要改换专有术语以追求表面差异；无法合理重述时可简短直接引述并标注。引述和释义都不能替代自己的分析。

**来源**：Unit 5 / Paraphrasing; Careful Use of Synonyms；书内 pp. 202–208；PDF 第 214–220 页。

<a id="awg-021"></a>

### AWG-021 区分通用表达、原创内容和直接／间接来源

**原书方法**：原书区分学界常用的句式骨架与作者独特的内容和表述；还建议尽可能核读原始来源，无法取得原始资料而转引时须明确转引关系。

**适用情境**：引用、文献摘要、句式借鉴及来源不足的材料整合。

**操作步骤**：整理者操作化：给每条借用内容标来源；区分通用句式与独特表述；直接引语使用适用标识；核读原始来源，不能取得时显式标明从何文献转引。

**限制与例外**：原书对 plagiarism 的历史性／意图性定义不作为现行规范判定；适用机构和期刊要求须另核实。原书示例引用并非本次已核读的原始论文。

**来源**：Unit 5 / Citing a Citation; Some Notes on Plagiarism; Summary Guidelines；书内 pp. 193–198; 208；PDF 第 205–210、220 页。

<a id="awg-022"></a>

### AWG-022 报告动词和引用位置应如实传达来源立场

**原书方法**：reporting verbs 可表达客观报告、推测、主张或评价；mention 会把信息呈现为较次要的点。长摘要中适时提醒来源，有助于区分来源作者与当前作者。

**适用情境**：文献综述和对前人结论的讨论。

**操作步骤**：整理者操作化：判断原文实际动作及证据强度；选择匹配的报告动词；明确作者／来源；较长摘要需要时补来源提示；检查自己的评论是否与来源观点混在一起。

**限制与例外**：不能仅为避免重复而把 suggest 改成 demonstrate；动词使用有学科差异。姓名和引用形式遵循适用样式，书中旧版样式说明不作当前格式标准。

**来源**：Unit 5 / Identifying the Source; Summary Reminder Phrases；书内 pp. 209–217；PDF 第 221–229 页。

<a id="awg-023"></a>

### AWG-023 多来源综合按问题和关系组织

**原书方法**：综合多个来源需要明确它们的重叠、分歧和冲突；只按年份逐篇罗列可能无法表现理解。原书建议用表、图或电子表格整理文章与关键点，再找共同线索。

**适用情境**：Introduction 的文献论证、Related Work 或 Discussion 的对照。

**操作步骤**：依据原书整理：建立来源×关键问题的记录；标出相同、不同和冲突结论；按主题或解释关系排序；写出综合判断并追溯到对应来源。

**限制与例外**：时间顺序并非绝对禁用：研究确有清晰线性发展时或某些子段落可采用。不能把不同设计或不同定义下的结果直接判为矛盾。

**来源**：Unit 5 / Syntheses of More than One Source; Unit 8 / Reviewing the Literature；书内 pp. 220–227; 343；PDF 第 232–239、355 页。

<a id="awg-024"></a>

### AWG-024 用问题—证据—结论链检查论证

**原书方法**：评价文献时应明确研究问题、收集何种证据、作者得出什么结论，以及结论是否由证据支持；重要假设和遗漏证据也应被考虑。

**适用情境**：核对本稿论证，或解释为何现有证据尚未解决问题。

**操作步骤**：整理者操作化：将问题、证据、结论和假设对应起来；检查结论是否回答问题；指出缺失连接和有实质影响的证据边界；结合其他相关研究判断。

**限制与例外**：原书用于文章评价；这里是迁移到写作自查的建议。yes/no 形式是帮助聚焦的教学策略，不应强改所有探索性或定性研究问题。

**来源**：Unit 6 / Evaluating a Published Article；书内 pp. 248–250; 257；PDF 第 260–262、269 页。

<a id="awg-025"></a>

### AWG-025 批评要符合学科、体裁和研究范围

**原书方法**：合理评价需采用适合该领域的标准，区分已研究问题与值得扩展的问题；短通信、会议摘要和完整论文的合理细节期待不同。

**适用情境**：界定研究缺口、讨论前人工作的局限或审查自身局限表述。

**操作步骤**：整理者操作化：先确认原文目标、体裁和可合理期待的证据；判断遗漏是否影响原文主张；把“没有研究另一个问题”与“当前论证不足”分开。

**限制与例外**：不能拿物理测量精度要求心理研究，也不能因研究没做所有扩展就判为失败；负面评价应有根据，正面与负面皆需具体。

**来源**：Unit 6 / Writing Critiques; Critical Reading；书内 pp. 228–229; 265–267；PDF 第 240–241、277–279 页。

<a id="awg-026"></a>

### AWG-026 评价语要对应具体成功、失败或限制

**原书方法**：评价可由名词、动词、形容词和副词承担；应说明具体做到了什么或没做到什么。could have、should have 等力度不同，评价词也有学科差异。

**适用情境**：对方法优点、前人局限或研究贡献的措辞调整。

**操作步骤**：整理者操作化：把“差／好／优越”等泛评改为具体对象和依据；检查评价强度；按需要区分未实施建议与已证实缺点。

**限制与例外**：simple/complex 等词在不同学科可有相反评价色彩；反事实表达不能证明修改后一定会更好。书评的自我呈现及口语化风格不自动迁移到科研论文。

**来源**：Unit 6 / Unreal Conditionals; Evaluative Language Revisited；书内 pp. 259–265；PDF 第 271–277 页。

<a id="awg-027"></a>

### AWG-027 全文各部分应形成相互支持的结构

**原书方法**：典型实证论文呈一般—具体—一般的整体形状；Introduction 提出理由，Methods 说明研究，Results 陈述发现，Discussion 解释意义。原书要求方法与结果相互对应，并建议引言与讨论紧密连接。

**适用情境**：全文提纲、结构重组及章节一致性检查。

**操作步骤**：整理者操作化：把研究问题对应到方法、结果和讨论；识别没有结果支撑的目的、没有方法交代的结果，以及无来源的讨论主张。

**限制与例外**：IMRD 是常见实证结构，不是所有科研论文的统一格式；理论、数学及某些建模论文有不同组织，合并 R+D 或多研究循环也可适用。

**来源**：Unit 7 / Types of Journal Publication; Longer Research Papers；书内 pp. 277–287；PDF 第 289–292、296–299 页。

<a id="awg-028"></a>

### AWG-028 Methods 的功能清单需要按研究选择和循环

**原书方法**：原书引用的 Methods 分析包括概述、目的／问题／假设、对象／材料、地点、程序、局限、分析七种功能；出现频率及顺序因学科而异，材料与步骤可循环。

**适用情境**：Methods 内容盘点与小节组织。

**操作步骤**：整理者操作化：按实际研究检查对象、环境、步骤和分析等信息；辨认读者需要的说明；按实验或分析单元组织相关材料与步骤。

**限制与例外**：七种功能不是七个必设标题；原书列出的频率来自特定样本，不能代表所有领域。没有出现独立局限段不表示研究没有局限。

**来源**：Unit 7 / Methods Sections；书内 pp. 289–295；PDF 第 301–307 页。

<a id="awg-029"></a>

### AWG-029 Methods 详略取决于可理解性、复现需要和方法新颖性

**原书方法**：标准化方法可简述并引用，改动应交代；新颖、争议性、跨学科或以方法本身为贡献的论文需要更多解释。凝练与扩展 Methods 是连续谱。

**适用情境**：缩短过长 Methods 或补充信息不足的 Methods。

**操作步骤**：整理者操作化：识别决定研究能否成立和复现的关键步骤；说明标准方法引用及实际修改；对不熟悉／有争议的选择补背景、过程及理由。

**限制与例外**：不能根据学科名自动省略细节；标准引用须可识别，且不能掩盖本研究的关键修改。原书提醒不要塞入与结果无关的信息。

**来源**：Unit 7 / Variation in Methods Sections；书内 pp. 295–301；PDF 第 307–313 页。

<a id="awg-030"></a>

### AWG-030 Methods 的连接要交代目的、时间和理由

**原书方法**：目的从句、时间短语及因果表达可说明为什么／何时采取步骤，减少读者对选择的疑问；某些扩展 Methods 可说明研究者决策。

**适用情境**：步骤列表缺乏合理性或研究路径难以理解。

**操作步骤**：整理者操作化：对关键选择交代目的；对有依赖的步骤标顺序；用提供的前期依据解释选择；检查 purpose clause 放置是否清楚。

**限制与例外**：不是每一步都需解释心理活动；过去已进行的步骤、原定目的和结果必须分开。书中“句首目的表达增加”的判断属作者推测，不作现行频率事实。

**来源**：Unit 7 / Linking Phrases in Methods Sections; Purpose Clauses；书内 pp. 301–304；PDF 第 313–316 页。

<a id="awg-031"></a>

### AWG-031 Results 要从数据中提出可支持的结果消息

**原书方法**：原书区分 data 与 results：数据是事实和数值，结果是说明这些数据表明什么的正文陈述，如差异、趋势或与问题相关的发现。

**适用情境**：有表格但正文缺少结果，或结果章节只有数据堆积。

**操作步骤**：整理者操作化：对每项研究问题提炼数据实际支持的消息；把消息与对应图表／统计量连接；避免把解释机制写成已观测的结果。

**限制与例外**：结果消息不能超出数据；书中示例并不授权重新计算或推断未提供的统计。Results 可以有何种评论仍需看章节安排和领域规范。

**来源**：Unit 7 / Data versus Results; Results versus Discussion；书内 pp. 305–309；PDF 第 317–321 页。

<a id="awg-032"></a>

### AWG-032 依据领域与章节安排决定 Results 评论范围

**原书方法**：原书列举 Results 可只报告、含少量评论或大量解释等不同情况；有些论文将 Results 与 Discussion 合并，不能简单规定结果部分不得解释。

**适用情境**：Results/Discussion 交叉重复或解释位置争议。

**操作步骤**：整理者操作化：识别目标体裁及 R/D 是否合并；参考同类论文确定评论深度；将与当前结果理解直接有关的说明和较广泛意义区分处理。

**限制与例外**：书中生化研究的频率只属于该样本；其中“未来研究放 Discussion”不能升级为所有学科绝对规则。不能以写作偏好覆盖期刊明确要求。

**来源**：Unit 7 / Results versus Discussion; Commentary in Results Sections；书内 pp. 306–309; 320–322；PDF 第 318–321、332–334 页。

<a id="awg-033"></a>

### AWG-033 按研究单元组织结果并循环呈现支持

**原书方法**：Results 小标题由调查／实验内容决定；不同领域可能循环使用准备信息、结果陈述、支持细节和评论。通常重要发现先于次要发现。

**适用情境**：较长 Results 的小节和段落组织。

**操作步骤**：整理者操作化：按问题或实验阶段分组；在每组交代必要上下文、结果及支持；需要时补受限评论；先安排能回答核心问题的结果。

**限制与例外**：原书三个领域的循环是描述性范例，不是固定顺序；“两三句结果配一句评论”是典型倾向而非配额。不得因重要性排序隐藏零结果。

**来源**：Unit 7 / The Organization of Results Sections；书内 pp. 323–326；PDF 第 335–338 页。

<a id="awg-034"></a>

### AWG-034 用 CARS 检查引言的三种功能

**原书方法**：CARS 将典型科研引言组织为建立研究领域、建立研究位置以及说明本研究如何占据该位置。重点是读者为何要读、已有知识与本研究如何连接。

**适用情境**：引言缺少研究动机、铺垫和研究目的不相接。

**操作步骤**：整理者操作化：标出领域背景及既有研究；指出待解决问题／扩展机会；检查本研究目的是否对应；补真正缺失的功能，而非只加套话。

**限制与例外**：原图的重要性陈述是 optional；研究问题、发现、价值和结构预告是 PISF，不能全部强制加入。某些工程现实问题可先论问题，再把既有解决方案放 Move 2；短通信可能不需显式 Move 2。

**来源**：Unit 8 / Introductions; Creating a Research Space; Figure 16；书内 pp. 327–331; 335–338; 348；PDF 第 339–343、347–350、360 页。

<a id="awg-035"></a>

### AWG-035 引用应服务相关性和论证功能

**原书方法**：相关性是原书强调的引用动机；引用可出现在引言各处，并非只在“文献综述段”。整合式引用突出作者，非整合式引用有助于保持内容为焦点。

**适用情境**：引言引用堆积、连续作者名单或文献与论点脱节。

**操作步骤**：整理者操作化：为每项引用确定支持、对照、归属或问题定位功能；按当前句子的焦点选择作者显式出现或括号／编号引用；检查引用是否确实支持该句。

**限制与例外**：原书讨论自引和名望的研究结果不是鼓励策略性自引；不能以作者知名度替代相关性。引用格式另按适用规范。

**来源**：Unit 8 / Reviewing the Literature; Motives for Citing; Variation in Reviewing the Literature；书内 pp. 340–346；PDF 第 352–358 页。

<a id="awg-036"></a>

### AWG-036 研究位置可以是纠正、补缺、澄清或延伸

**原书方法**：Move 2 的选择包括反驳、指出缺口、提出问题／推论和延续传统；科学与工程中的扩展既有工作可以成立，不必都声称前人错误。

**适用情境**：贡献定位、研究缺口及 novelty 表述。

**操作步骤**：整理者操作化：根据文献证据判断未决问题类型；说明为何有必要研究；让下一步目的自然回应；对范围有限的检索避免绝对“无人研究”。

**限制与例外**：短通信可能不需该步；强反驳在某些争议学科更常见。加 to our knowledge 不使未经核查的首创声称自动成立；这个准确性要求为技能转化的补充约束。

**来源**：Unit 8 / Move 2: Establishing a Niche; Negative Openings；书内 pp. 348–352；PDF 第 360–364 页。

<a id="awg-037"></a>

### AWG-037 多个研究问题可用累积或循环的缺口组织

**原书方法**：累积式 Move 2 用逐步收窄的一组缺口引向精确问题；循环式则把相关研究分成几部分，分别指出限制或待解问题。

**适用情境**：包含多条方法动机或多个相互关联子问题的长引言。

**操作步骤**：整理者操作化：识别子问题间关系；若逐层收窄则累积展开；若对应不同文献分支则分组综述—评价；最后与研究目标统一对接。

**限制与例外**：不必为每篇文献配一个缺点；循环次数由论证需要决定。原书案例是分析手段，不是要求所有引言增加篇幅。

**来源**：Unit 8 / Cumulative and Recycling Move 2s；书内 pp. 352–354；PDF 第 364–366 页。

<a id="awg-038"></a>

### AWG-038 用目的或研究描述完成引言，并选择必要附加信息

**原书方法**：Move 3 可说明主要目的，也可描述本研究的核心特征；还可能列研究问题／假设、主要发现、价值或论文结构。

**适用情境**：引言末段与全文任务的对接。

**操作步骤**：整理者操作化：明确本研究做什么及其对应问题；必要时补次要目的；根据领域和期刊选择是否预告结果、价值、结构；检查没有超出正文实际内容。

**限制与例外**：附加信息均有领域条件；有摘要时是否再次预告结果，原书建议考虑冗余但并未绝对禁止。结构预告在非标准格式或部分技术领域更有必要。

**来源**：Unit 8 / Occupying the Niche; Completing an Introduction；书内 pp. 355–361；PDF 第 367–373 页。

<a id="awg-039"></a>

### AWG-039 时态应区分研究活动、现有知识和本文文本

**原书方法**：原书的通用倾向是：具体已完成研究活动用过去时，研究领域累积用现在完成时，当前知识可用现在时；引用动词、从句和目的句又有修辞与学科弹性。

**适用情境**：文献综述、目的句和摘要的时态修订。

**操作步骤**：整理者操作化：先判断句子说的是过去活动、仍有效命题还是当前文章内容；再选择时态；对全文统一的是语义原则而非单一时态。

**限制与例外**：原书强调这不是死规则；研究行为与作者所写／所想可不同。生物医学目的句常见 was；现在时从句可能使单研究发现变成更一般断言，不能无意扩大范围。

**来源**：Unit 8 / Citation and Tense; Purpose Statements and Tense; Abstracts；书内 pp. 344–346; 356; 386–387；PDF 第 356–358、368、398–399 页。

<a id="awg-040"></a>

### AWG-040 Discussion 通过关键结果与解释循环展开

**原书方法**：讨论不只是摘要，而要把结果连接到更广知识与现实意义。原书综合的功能包括可选背景、关键结果、评论解释、局限和建议，主体常循环“结果—解释／比较”。

**适用情境**：Discussion 的论证结构和重复结果问题。

**操作步骤**：整理者操作化：选核心发现；解释其对问题的意义；与既有研究比较；考虑有根据的替代解释；视需要写局限及后续建议。

**限制与例外**：原书将关键结果与评论标为必需，但背景、局限独立段和建议为可选或领域相关；这不授权隐瞒实质限制。不可把物理领域的 proof 用语普遍化为“证明”。

**来源**：Unit 8 / Discussion Sections; The Structure of Discussion Sections；书内 pp. 363–369；PDF 第 375–381 页。

<a id="awg-041"></a>

### AWG-041 讨论的概括与局限共同界定可得结论

**原书方法**：讨论通常比 Results 更概括而又不脱离结果；局限不仅是缺点清单，也应说明研究不能支持哪些结论、哪些范围不应外推。长讨论可从较具体逐步走向更一般。

**适用情境**：夸大外推、模板式局限以及结论与结果不一致。

**操作步骤**：整理者操作化：为概括保留必要例外与范围；明确研究对象和未覆盖问题；说明哪种结论不能得出；将仍有意义的发现与这些边界并列呈现。

**限制与例外**：不能把篇幅压缩当作抹去例外的理由。原书承认独立局限段不是所有体裁必设；真实限制无论放哪里都应清楚。

**来源**：Unit 8 / Levels of Generalization; Limitations in Discussion Sections; Longer Discussion；书内 pp. 371–378；PDF 第 383–390 页。

<a id="awg-042"></a>

### AWG-042 标题应准确传递主题、范围与适用风格

**原书方法**：标题应让领域读者理解研究主题和范围，不夸大也不低估；名词短语、陈述句、疑问句、冒号和限定词的选择因学科和期刊而异。

**适用情境**：拟标题、缩短标题或纠正范围误导。

**操作步骤**：整理者操作化：识别主题及限定范围；选择符合内容和目标要求的形式；检查必要的研究类型信息；去掉无贡献词语，保留关键边界。

**限制与例外**：研究类型并非一律必写；没有固定通用词数。作者反对新作者用巧妙／玩笑标题带有职业阶段语境，不应宣称所有学科禁止此类标题。

**来源**：Unit 8 / Titles；书内 pp. 378–383；PDF 第 390–395 页。

<a id="awg-043"></a>

### AWG-043 摘要可围绕结果或概述全文，但须与正文相符

**原书方法**：原书区分结果驱动摘要和逐部分概述摘要，也区分只说明做了什么的 indicative 与包括主要发现的 informative；结构式小标题由期刊要求决定。

**适用情境**：已有全文生成摘要，或摘要结构与论文不一致。

**操作步骤**：整理者操作化：选适合内容的组织；提炼目的、必要方法、主要发现及可支持的结论；检查与全文一致；最后按期刊长度与结构要求压缩。

**限制与例外**：原书称本节只是简要处理。书内 p.384 关于“无法报告发现的理论论文却更 informative”的句子与前文定义矛盾，原页已核实，本次不转化为规则，待勘误／其他版本核验。无结果不能补造信息性摘要。

**来源**：Unit 8 / Abstracts；书内 pp. 384–387；PDF 第 396–399 页。

<a id="awg-044"></a>

### AWG-044 致谢按支持事实及责任关系组织

**原书方法**：原书列出资助、感谢和可选免责声明等常见内容；通常先资助后感谢，若允许可用 I/we，其他事项可含许可或材料来源。

**适用情境**：原始论文的致谢段整理。

**操作步骤**：整理者操作化：收集已确认的资助与帮助事实；按实际贡献写感谢；只有确实适用时加入资助方免责声明或其他说明；核查姓名、机构及编号。

**限制与例外**：书末教学练习要求“必要时虚构帮助”仅适用于练习，绝不迁移至真实稿件。致谢不自动等于作者资格、许可或所有利益披露，需另按适用要求处理。

**来源**：Unit 8 / Acknowledgments；书内 pp. 387–389；PDF 第 399–401 页。
