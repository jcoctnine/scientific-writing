## 方法卡片

<a id="wsra-001"></a>

### WSRA-001 先明确文章的交流对象与成功标准

- **原书方法**：写作先考虑受众、目的、格式、评估四项；科研同行是最终读者，编辑与审稿人是文章进入传播前必须满足的读者。作者应知道文章如何参与该领域正在进行的讨论。
- **适用情境**：起草或重构整篇论文，尤其是不清楚应该解释多少背景、突出什么贡献时。
- **操作步骤**：〔提取者操作化〕列出主要读者、希望读者获得的知识、已知格式约束、评估文章所需证据；用这四项检查拟写内容的相关性。
- **限制与例外**：作者区分写作与发表技能；满足表达与格式要求不等于科学贡献足够。书中选刊操作不是本阶段要建的期刊定制模块。
- **来源**：第1章§1.1–1.3，本书pp.3–7；PDF17–21。

<a id="wsra-002"></a>

### WSRA-002 把体裁结构当作可检验的选择集合

- **原书方法**：分析本领域文章的结构与语言来扩充写法；AIMRaD常见但不是唯一结构。其他形式包括Methods后置、Results/Discussion合并后加结论，以及按主题组织的AIBC主体。
- **适用情境**：建立提纲、评估结构是否适合实验或计算研究。
- **操作步骤**：〔提取者操作化〕识别目标文章的信息功能；比较已提供范文的标题与各节安排；选择能承载该研究叙述的结构，再检查领域/期刊约束。
- **限制与例外**：作者明确称其研究概括是描述而非处方；AIBC小节名由内容决定，不能强制重命名为IMRaD；书中以实验研究为主要基础，不能原样扩展至所有人文社科文类。
- **来源**：第1章§1.5、第2章§2.1、第6章末；本书pp.10–16、36；PDF24–30、50。

<a id="wsra-003"></a>

### WSRA-003 用结果证据连接各节的研究问题与论证范围

- **原书方法**：沙漏图强调Results对整篇内容的统摄：Introduction从读者关心的较宽问题收束到本研究，Methods说明结果如何获得，Discussion从结果返回较宽意义。
- **适用情境**：稿件出现背景过宽、方法无对应结果、讨论离开研究问题时。
- **操作步骤**：〔提取者操作化〕将引言目的、主要结果、获得结果的方法及讨论意义一一对应；找出无证据支撑或未铺垫的主张，并缩小、补证或移除。
- **限制与例外**：图的宽度表示论述范围而非章节字数；这一逻辑可以用于变体结构，不能据沙漏形状推导固定篇幅比例。
- **来源**：第2章§2.1、图2.1；本书pp.11–12；PDF25–26。

<a id="wsra-004"></a>

### WSRA-004 用评阅问题检查可定位的证据

- **原书方法**：典型评阅标准关注贡献的新颖性与重要性、组织、方法和结果处理、结论依据、图表必要性、标题摘要及引用；写作者可提前找出这些标准的证据位于何处。
- **适用情境**：整篇初稿自查、正式提交前的内容检查。
- **操作步骤**：〔提取者操作化〕逐项查找支撑位置；标记“已有证据”“表述不清”“材料缺失”；针对缺口修改相应段落。用表15.1继续检查目的—结果是否对应、图表能否独立读懂及引文双向完整性。
- **限制与例外**：图3.1是作者综合的常见问题，表15.1也允许按学科调整；不是所有期刊统一表单，更不能由语言技能认证统计方法的科学有效性。
- **来源**：第3章及图3.1、第15章§15.3与表15.1；本书pp.17–18、112–113；PDF31–32、126–127。

<a id="wsra-005"></a>

### WSRA-005 从图表提炼结果故事与核心带走信息

- **原书方法**：起草前先找出相互连接的结果故事及一个或多个take-home messages；逐图表写一两个主要信息点，区分结果陈述与讨论解释，再排序并与合作者协商。
- **适用情境**：已有数据/图表但尚未形成论文主线。
- **操作步骤**：〔忠实转述原书流程〕逐图表写要点并标R/D；排序连接；回答结果说了什么、在语境中意味着什么、谁需要知道、为什么需要知道；据此拟定核心信息。
- **限制与例外**：四问以已有结果为起点；“故事”不能替代证据，也不授权隐藏反例或不显著结果。团队署名、纳入数据的科研决定仍需作者负责。
- **来源**：第4章及Task 4.1；本书pp.23–24；PDF37–38。

<a id="wsra-006"></a>

### WSRA-006 按读者需要选择图、表、文字与补充材料

- **原书方法**：图表选择取决于要传递的意义：表有利于精确数值、多方向比较与计算；图有利于整体趋势和少量元素的关系。正文纳入讲清研究所需的数据，扩展信息可考虑补充材料。
- **适用情境**：数据呈现重复、正文过载，或读者难以找到关键比较时。
- **操作步骤**：〔提取者操作化〕为每组数据写出读者任务；需要精确值/计算则优先表，需要趋势/形状则考虑图；简明信息可用文字；检查证据是否仍完整、各图表是否按引用顺序编号。
- **限制与例外**：作者称图表建议不是具体不变规则；补充材料同样受必要性审查。选择载体不意味着删除必要证据或把不支持主张的数据藏到补充材料。
- **来源**：第5章总论、§5.1及表5.1；本书pp.25–26；PDF39–40。

<a id="wsra-007"></a>

### WSRA-007 让图形突出真正要比较的关系

- **原书方法**：先决定主要信息，再决定图类型、符号、线条、刻度及统计标记；同一处理在多图中保持符号与顺序一致，去除干扰，并在期刊最终尺寸检查可读性。
- **适用情境**：图形能显示数据但难以看出结果意义，或不同图难以比较时。
- **操作步骤**：〔提取者操作化〕明确图的主要比较；检查图型是否造成不存在的关系；统一符号/顺序；删去不传递信息的装饰；按最终尺寸查看标签和线条。
- **限制与例外**：原书“3:2较美观”、边框偏好及图5.2用LSD条替代误差条均有特定语境，不转为普遍设计/统计规则；统计信息能否替换须另行判断，不能为了简洁抹去不确定性。
- **来源**：第5章§5.2、图5.1–5.2；本书pp.26–29；PDF40–43。

<a id="wsra-008"></a>

### WSRA-008 用表格排序与精度帮助读者发现结果

- **原书方法**：清楚的行列标题、有意义的数据排序、适当精度及简洁布局能减少读表负担；避免与论点无关或冗余的数据，同时保留读者进行重要计算所需信息。
- **适用情境**：大表按采集顺序机械排列、精度过细或行列关系难读。
- **操作步骤**：〔提取者操作化〕识别表格主要比较方向；按与比较有关的变量排序；检查单位、简称、有效精度和汇总行；核查关键计算所需数据是否遗漏。
- **限制与例外**：排序与舍入不能改变数据含义。p.30的“non-significant or over-precise numbers”在精度/冗余语境中表述含混，不能据此删除统计不显著结果；原书不用外框等版式建议受期刊约束。
- **来源**：第5章§5.3、表5.2–5.3及Task 5.2；本书pp.29–31；PDF43–45。

<a id="wsra-009"></a>

### WSRA-009 图题、图注与表注应支持独立理解

- **原书方法**：图表及其说明应能独立传达该部分结果；图注通常包含主题、结果/模型细节、必要方法或组件说明、单位/统计记号及其他符号说明，部分顺序可交错。
- **适用情境**：读者需要翻回正文才能解释图中对象、误差线或缩写时。
- **操作步骤**：〔提取者操作化〕暂时遮去正文，检查图表主题、对象、比较及统计符号是否能理解；补足缺失信息；去掉与理解此图无关的细节。
- **限制与例外**：五部分是常見形式，不是每图必须五句；表题的细节通常更简短，部分信息宜放脚注；说明关键发现仍须忠实于数据。
- **来源**：第5章总论及§5.4；本书pp.25、31–32；PDF39、45–46。

<a id="wsra-010"></a>

### WSRA-010 Results以突出发现和定位证据为主

- **原书方法**：Results文字通常突出重要发现、指向图表，并可能作适量评论；不应逐项复述图表。分立Results一般描述数值显示什么，解释与跨研究比较主要在Discussion。
- **适用情境**：Results像图表数据转录，或结果与讨论边界混乱时。
- **操作步骤**：〔提取者操作化〕保留支持讨论主线的关键发现；为每个发现给出图表位置；检查重复数值；根据分立或合并格式决定解释的位置。
- **限制与例外**：书中承认某些不再详细讨论的结果可在Results附带前人比较；合并Results/Discussion和AIBC不服从严格分立规则，不能一律删除解释性句子。
- **来源**：第6章总论、§6.1–6.2；本书pp.33–34；PDF47–48。

<a id="wsra-011"></a>

### WSRA-011 按陈述功能选择时态

- **原书方法**：描述已完成研究做了什么、发现什么通常用过去时；描述持续成立的信息或论文图表本身常用现在时；评论可能用may、could等情态表达。
- **适用情境**：Results时态不稳定，或把所有句子强改成同一时态时。
- **操作步骤**：〔提取者操作化〕先判句子在谈已完成观察、普遍陈述、文件内容还是解释；再选择时态；遇到稳定的领域差异时参照多篇范文。
- **限制与例外**：作者明确允许本领域文章提供与书中概括不同的模式；时态与论断强度相关但不是事实真实性的证明。
- **来源**：第6章§6.3；本书pp.34–36；PDF48–50。

<a id="wsra-012"></a>

### WSRA-012 Methods既要便于复现，也要让结果可信可评估

- **原书方法**：Methods不只叙述实验过程，还提供读者判断结果是否具有作者所说含义的依据。已发表方法可引用，但修改之处要说明；新方法详细描述，原来源难以获取时也宜补充细节。
- **适用情境**：方法写成实验流水账，或过度依赖“如文献所述”而无法评估结果时。
- **操作步骤**：〔提取者操作化〕逐项列出支持结果判断所需的方法信息；区分原方法、修改、新方法；补写修改和不可获得来源中的必要内容，并保留引用。
- **限制与例外**：书中“可引用已有方法”不是可省略必要参数的许可；它未提供各学科完整的报告规范，本阶段不能由此宣称已满足全部可复现性要求。
- **来源**：第7章§7.1；本书p.37；PDF51。

<a id="wsra-013"></a>

### WSRA-013 让Methods组织与目的、Results互相指引

- **原书方法**：相似的Methods/Results小标题和说明目的的开头句能帮助读者建立对应关系；段首交代本段内容并连接已知信息。许多领域有常见顺序，应检查相似研究。
- **适用情境**：读者从某一结果跳读到Methods时无法找到对应程序。
- **操作步骤**：〔提取者操作化〕将结果子题与方法子题对照；补上有信息量的小标题；必要时用目的引导句；按学科习惯和研究逻辑排列。
- **限制与例外**：相同标题是连接策略之一，不要求标题机械一致；采用AIBC时方法可分布在多个主体小节。
- **来源**：第7章§7.2；本书p.38；PDF52。

<a id="wsra-014"></a>

### WSRA-014 主动或被动语态由施事信息与衔接决定

- **原书方法**：被动语态可突出动作、淡化无关施事并维持旧信息在前；主动语态可直接、简洁。两者选择还受we重复及领域惯例影响；避免长主语后仅剩短被动谓语的头重句。
- **适用情境**：Methods大量重复we，或过长的被动句使动作难以辨认。
- **操作步骤**：〔提取者操作化〕判断施事是否重要、句首应承接何种信息；选择更清晰的语态；将冗长清单移至谓语之后；必要时省略重复助动词而保留明确关系。
- **限制与例外**：不“一律主动”或“一律被动”；书中前九词出现主谓是可读性提示，不是必须达成的字数门槛。不能在改被动时丢失对研究有意义的施事者。
- **来源**：第7章§7.3与表7.1；本书pp.39–42；PDF53–56。

<a id="wsra-015"></a>

### WSRA-015 Introduction用阶段功能解释研究必要性

- **原书方法**：常见阶段为研究背景/重要性、已有工作、需要延伸的缺口、研究目的/活动/主要发现，以及可选价值和文章路线图；可由较宽领域逐步聚焦到具体主题。
- **适用情境**：引言像无目的文献摘要，或研究目的突然出现。
- **操作步骤**：〔提取者操作化〕给现有句段标注交流功能；检查背景如何缩小、已有工作如何引出未解决问题及本研究如何回应；补足中间逻辑而不是补齐固定段数。
- **限制与例外**：阶段可以重复、重排；编号不是出现次序。“领域—子领域—主题”的缩放只是一种思考工具，具体主题不等于研究目的。价值和路线图不是必需项。
- **来源**：第8章§8.1–8.2、图8.1、§8.7；本书pp.43–47、52–53；PDF57–61、66–67。

<a id="wsra-016"></a>

### WSRA-016 以论证需要组织引用，避免作者名单式综述

- **原书方法**：引用既证明了解已有研究，也支撑本研究必要性。信息突出、作者突出和弱作者突出等引用形式可服务不同论证功能；作者突出形式过多会使段落像列表。
- **适用情境**：连续“A发现…B发现…”但缺少综合关系的Introduction。
- **操作步骤**：〔提取者操作化〕先确定段落要证明什么；按共识、差异或方法限制组织研究；只在作者身份/分歧本身重要时突出作者，并用准确报告动词表现立场。
- **限制与例外**：作者突出引用并非错误，可能特别适合比较争论或接近具体研究缺口时使用；报告动词不能把尚未确认的发现写成既定事实。
- **来源**：第8章§8.3及表8.3；本书pp.47–50；PDF61–64。

<a id="wsra-017"></a>

### WSRA-017 让每项借用信息的来源持续清晰

- **原书方法**：避免无意剽窃需保持笔记中原作者观点、原话与自己的话可区分；即使拆分句子，也应让读者知道后一句的限制或判断是谁提出。科技论文通常释义而非长引原话。
- **适用情境**：由阅读笔记转稿、重写引文句或拆分长句时。
- **操作步骤**：〔提取者操作化〕标记每一事实/解释的出处；释义后核对含义；拆句后重新检查归属；未读到原始来源时标示转引关系并核对目标格式。
- **限制与例外**：引用并不能使逐字复制自动合适；书中只将剥离研究内容的句式框架作为语言学习方法。转引的具体参考文献处理方式受期刊规范约束。
- **来源**：第8章§8.3–8.4、Task 8.6；本书pp.50–51；PDF64–65。

<a id="wsra-018"></a>

### WSRA-018 用具体缺口衔接目的，并按需要交代价值与路线

- **原书方法**：缺口可在引言早期较宽地提出，随后细化；目的句为后文建立预期，可表述目标、主要活动或发现。价值陈述和文章路线图是否出现取决于领域与期刊。
- **适用情境**：缺口只有“研究很少”，而目的和后续研究内容对应不清时。
- **操作步骤**：〔提取者操作化〕明确尚不清楚的关系/限制/需扩展之处；将目的句紧接该需要，包含研究真正涉及的重要条件；检查标题关键词是否得到兑现；只在有用时加价值或结构指引。
- **限制与例外**：however、unclear等只是信号词，不是缺口真实性证据；重要性不能仅由使用这些词获得。原书没有要求每篇都在引言报告结果或贡献清单。
- **来源**：第8章§8.5–8.7及Task 8.10；本书pp.51–53；PDF65–67。

<a id="wsra-019"></a>

### WSRA-019 引言可按目的→缺口→背景→已有工作起草

- **原书方法**：在已决定纳入哪些结果、以及这些结果对读者意味着什么后，可先写目的/主要活动，再写缺口，再选择背景起点，之后组织文献，最后连接并调整为连贯引言。
- **适用情境**：从空白页写Introduction，背景越写越宽而无法收束时。
- **操作步骤**：〔忠实转述原书次序〕先完成阶段4，再阶段3，再阶段1，再组织阶段2或2/3循环；最后补必要背景、调整次序与过渡。目的句包含研究重要参数/议题，避免后文突然出现未铺垫部分。
- **限制与例外**：这是起草顺序，不是文章呈现顺序；目的句通常最终仍在引言末部。该建议有“结果及读者意义已定”的前提，不强加于缺少结果的研究计划。
- **来源**：第8章§8.8；本书p.53；PDF67（已核页图）。

<a id="wsra-020"></a>

### WSRA-020 用读者预期、由概括到细节和旧→新信息改善衔接

- **原书方法**：有信息量的标题/小标题/主题句先建立预期，再尽快兑现；由概括推进到细节，旧信息靠前、新信息靠后；尽早提供前后句联系及主谓，减少读者等待。
- **适用情境**：句子都正确，但读者需要反复回读才能建立联系时。
- **操作步骤**：〔提取者操作化〕逐段检查主题与细节层级；标出每句承接信息与新信息；改写迟到的连接点；把长列举后置；必要时转换语态来保持话题连续。
- **限制与例外**：原书建议联系点与主谓在前7–9词出现，这是诊断提示，不是计数考核；段首“常常但不总是”主题句。主动/被动选择从属于信息流。
- **来源**：第8章§8.9（并见§8.2）；本书pp.47、54–57；PDF61、68–71。

<a id="wsra-021"></a>

### WSRA-021 Discussion与引言问题、标题主张相互对齐

- **原书方法**：讨论在已接受知识背景下解释新发现并限定意义；讨论完成后回看引言，让重要问题已得到铺垫，同时使标题反映主线。是否加结论、小标题或合并Results取决于结构需要。
- **适用情境**：Discussion出现全新主题，或结尾没有回答引言问题。
- **操作步骤**：〔提取者操作化〕列出讨论主要信息，与目的、缺口和背景逐项核对；必要时调整引言或标题；检查独立结论/小标题是否真能帮助读者。
- **限制与例外**：引言不必预先包含讨论引用的全部文献；相互对应不等于重复同一背景或全部结果。书中讨论原则也适用于不叫Discussion的讨论性文本。
- **来源**：第9章总论及§9.1；本书pp.59–60；PDF73–74。

<a id="wsra-022"></a>

### WSRA-022 按重要发现组织讨论的解释、比较与边界

- **原书方法**：可考虑研究目的/假设、主要发现及其对目的的贡献、与他人结果比较、解释/有文献支持的推测、限制、较宽意义及未来研究/应用；发现—解释—限制—意义可按结果组循环。
- **适用情境**：讨论只是重复结果，或一段同时堆积许多无法连接的解释时。
- **操作步骤**：〔提取者操作化〕按重要性选出需要讨论的发现；分别检查支持/偏离预期、文献比较、解释依据及适用边界；用主题句标明各讨论单元要传递的主张。
- **限制与例外**：不是每项结果都必须写齐所有信息；推测不能写成观察事实，局限应限制推广范围而非仅列礼貌性套话。
- **来源**：第9章§9.2；本书pp.60–61；PDF74–75。

<a id="wsra-023"></a>

### WSRA-023 让措辞强度与数据和论证强度相称

- **原书方法**：主句报告动词及其时态、that从句的时态和情态动词都会改变主张强度；应以Results/Discussion中实际证据的强度决定表达，而非追求最强表述。
- **适用情境**：讨论把可能机制写成已证实，或谨慎措辞掩盖明确观察时。
- **操作步骤**：〔提取者操作化〕拆分直接观察与推断；检查主句动词及从句情态；根据证据是否直接、范围是否受限来选择表述，并保存必要限制。
- **限制与例外**：原书p.63在说明Example 5后写“Example 4”最弱，属于内部编号矛盾（已核页）；不能据此建立固定词汇强弱表。词的强度受上下文影响，词汇替换不会增加证据。
- **来源**：第9章§9.3、表9.1–9.2；本书pp.62–64；PDF76–78。

<a id="wsra-024"></a>

### WSRA-024 标题兼顾信息、关键词与适合的句法形式

- **原书方法**：标题应让目标读者判断相关性，以简洁方式给出足够信息，把关键概念尽量前置；名词短语、陈述句、问句可按研究信息与期刊习惯选择。
- **适用情境**：标题过泛、关键词被“Effects of”等空泛开头推后，或结果导向标题过度承诺。
- **操作步骤**：〔提取者操作化〕提炼读者检索的核心词和论文主张；构造几种题型；检查每种是否准确、具体且无歧义；全稿完成后选择最贴合主线的一种。
- **限制与例外**：原书仅建议当研究回答具体问题且答案不复杂时用陈述式标题；答案复杂时可考虑问句，但仍需检查期刊规定。不能把所有标题都改成因果断言。
- **来源**：第3章§3.1、第10章§10.1–10.3；本书pp.18–19、65–67；PDF32–33、79–81。

<a id="wsra-025"></a>

### WSRA-025 拆开名词串核对科学关系与中心词

- **原书方法**：长名词串易隐藏of、by、for等不同关系；先识别中心词，再必要时补介词解除歧义。领域名词短语需要准确学习，尤其注意名词作修饰语的单复数习惯。
- **适用情境**：标题或正文压缩过度，读者不能确定“谁对谁产生作用”。
- **操作步骤**：〔提取者操作化〕找中心词；把压缩名词串展开成完整关系；确认含义唯一后再决定保留或加介词；用领域实例检查固定术语与单复数。
- **限制与例外**：第10章提出通常最多三词及修饰名词“总用单数”，第17章改用“一般”并建议记录实际用法；这些不是无例外语法定律。不按词数拆坏规范术语。
- **来源**：第10章§10.4、第17章§17.4；本书pp.67、128–129；PDF81、142–143。

<a id="wsra-026"></a>

### WSRA-026 摘要先覆盖所需信息，再按约束压缩

- **原书方法**：摘要可能是读者唯一能获得的内容；完整摘要通常涉及背景、目的与范围、方法、主要结果、结论/建议，也可能压缩为目的+方法、结果、结论。
- **适用情境**：由全稿写摘要，或摘要只有背景和笼统结论。
- **操作步骤**：〔忠实转述并整理〕先为适用信息要素写句子并合成初稿；核对目标期刊字数和结构要求；再依重要性压缩，保留关键结果与意义。
- **限制与例外**：要素不是固定句数；结构化/非结构化形式和篇幅以当前要求为准。书中2008年的期刊摘要字数示例未核查现行有效性，不作为默认值。
- **来源**：第11章§11.1、11.3及Task 11.3；本书pp.69–71；PDF83–85。

<a id="wsra-027"></a>

### WSRA-027 关键词服务检索与专业匹配

- **原书方法**：除标题词外，参考相关文献和索引词，预测目标读者会如何检索；编辑也可能用关键词匹配审稿专业。
- **适用情境**：设置附加关键词或检查可发现性。
- **操作步骤**：〔提取者操作化〕列研究对象、方法、核心问题和用途的准确术语；检查标题已含哪些词；选择能覆盖读者检索路径并准确表征研究的词。
- **限制与例外**：关键词不是迎合指标的宣传标签；本章不提供所有学科的受控词表，也没有统一关键词数量要求。
- **来源**：第11章§11.2；本书p.69；PDF83。

<a id="wsra-028"></a>

### WSRA-028 把整篇起草拆成依赖结果的可迭代步骤

- **原书方法**：作者给出一种可能流程：确认结果包和核心信息、获得反馈及格式要求，完善图表，写Results和讨论要点，拟标题、Methods、Introduction、Discussion/Conclusion、Abstract、关键词，再整合。
- **适用情境**：从结果材料组织首份全稿，或合作者写作顺序反复返工时。
- **操作步骤**：〔忠实转述原书主要次序〕先定结果与图表信息，再写结果及讨论要点；依次起草所需各节，整合后回改。作者团队另行商定任务分工、署名、时间与看稿节点。
- **限制与例外**：书中明说有许多流程，这只是可能的一种；不要求已有成熟稿件推倒重来，也不能由技能替团队决定署名/研究数据取舍。
- **来源**：第15章§15.1；本书pp.109–110；PDF123–124。

<a id="wsra-029"></a>

### WSRA-029 分开内容、衔接、语言、引用与版面检查

- **原书方法**：修改先通读并标出内容问题，解决科学内容后再检查篇章衔接，接着拼写/标点/语法、引用一致性、版式及最后通读；脱离上下文逐句倒读可帮助专注语法。
- **适用情境**：全稿反复润色但主线问题仍在，或修改检查相互干扰时。
- **操作步骤**：〔提取者操作化〕分轮标注内容、信息流、句法、引文和排版问题；先修内容再修语言；核对正文引文与文后条目双向对应、格式及异常；最后整稿读通。
- **限制与例外**：原书建议人类作者放下稿件至少48小时、纸上倒读，属于认知辅助建议，不是技能等待指令；拼写或文献软件不能保证词义/元数据正确。用户范围限制优先。
- **来源**：第15章§15.2；本书pp.110–113；PDF124–127。

<a id="wsra-030"></a>

### WSRA-030 让反馈范围与作者当前需要一致

- **原书方法**：给反馈前先了解作者要内容反馈、语言反馈还是整体评估，并选择教练、评估者或教学等角色；早期稿件可只抓重要问题，给出优点和优先修改项。预审清单可帮助外部读者定向反馈。
- **适用情境**：请求“只看逻辑”却收到大量改词，或初稿被过多细节意见淹没。
- **操作步骤**：〔提取者操作化〕从用户请求识别范围与稿件阶段；分清事实错误、理解困难、可选风格建议；先处理会影响主线的问题，必要时给简短优先级总结。
- **限制与例外**：不是每次都要再问一次范围；明确请求本身已经提供范围。正式同行评审、写作小组组织与回复训练不纳入本阶段。
- **来源**：第15章§15.3、第16章§16.3；本书pp.113、118–120；PDF127、132–134。

<a id="wsra-031"></a>

### WSRA-031 先保护可理解性，再解决语言准确性

- **原书方法**：科学内容要能被清楚理解；复杂且不准确的句法、情态或时态选择可能显著影响含义。作者建议先写较短句，再按需要连接，并积累适合本领域的表达方式。
- **适用情境**：非母语初稿句子过度复杂，或润色可能改变研究含义。
- **操作步骤**：〔提取者操作化〕优先找会改变科学含义的句法、情态、时态和指代问题；先拆成明确命题；需要时再组合；最后核对主谓、单复数、介词、词性等准确性。
- **限制与例外**：原书“两分句起步”是学习策略，不是最终论文的硬句长限制；答案页也明确所有错误类型在某些情况下都可影响含义，不能把冠词或单复数错误一概判为轻微。
- **来源**：第17章§17.1–17.2、Task 17.1及其答案；本书pp.123–125、207、210；PDF137–139、221、224。

<a id="wsra-032"></a>

### WSRA-032 从范文抽取功能框架，而不是复制研究内容

- **原书方法**：将句子的研究特定名词短语剥离，留下可复用表达框架，并记录被替换成分的语法特征；按章节组织笔记。仅当框架能表达自己的原意时才使用。
- **适用情境**：学习领域常用的目的、方法或推断表达。
- **操作步骤**：〔提取者操作化〕识别句子功能；标出研究特定内容并抽去；记录槽位是名词短语、动名词或其他成分；用自己的真实内容重建句子，复核含义和引用。
- **限制与例外**：模板不是借用他人结果或独创论证的许可；书中对此区分尤其限定于科学写作，对人文社科不可直接套用；不为套句改变真实研究问题。

### WSRA-033 用领域语料检验搭配与术语用法

- **原书方法**：一致性检索工具可在一组本领域文本中查看词前后语境，学习搭配、介词、可数性和名词组合。语料应同子领域、同目标文类且质量适宜，并清理页眉、参考文献等干扰。
- **适用情境**：一般英语判断不足以决定领域术语表达时。
- **操作步骤**：〔提取者操作化〕明确待验证用法；收集适合的合法可用范文；以词及邻近词检索；阅读真实上下文并比较模式，而不只看出现次数。
- **限制与例外**：原书20–30篇是建议规模，不是充分代表性的证明；AdTAT是当时工具示例，未核实当前可用性。不能仅凭作者姓名/机构推断英语质量，也不能以高频代替科学准确。

### WSRA-034 冠词取决于当前指称，而非出现次数

- **原书方法**：先判断名词短语是在泛指一类还是特指双方可识别的对象，再看可数性和单复数；泛指概念反复出现仍可保持泛指。特指可来自共同知识、前文或后置限定。
- **适用情境**：把“第二次出现就加the”机械用于科学概念，或改变冠词后研究对象范围变化。
- **操作步骤**：〔提取者操作化〕判断当前所指是否唯一可识别；再确定可数/不可数与数；选择a/an、the或零冠词；遇领域特有用法回查语料。
- **限制与例外**：原书另承認the+单数有泛指类别的用法，简化流程图不能覆盖全部英语冠词情形。p.135称NP1 of NP2约85%特指，是书中经验性提示，不能变成自动加the规则；答案页承认可数性有语境争议。
- **来源**：第17章§17.6及图17.1、相关答案说明；本书pp.133–136、211–212；PDF147–150、225–226。

### WSRA-035 关系从句的限制性决定逗号与意义

- **原书方法**：限制性从句界定是哪一部分对象，不用逗号；非限制性从句增加补充信息，用逗号隔开，书中示例用which。关系词与动词省略后，标点区别仍影响含义。
- **适用情境**：which/that或逗号修改可能把某个亚组属性扩大到所有对象时。
- **操作步骤**：〔提取者操作化〕移除从句后检查对象指称是否仍正确；若删去会改变界定则按限制性处理，若为补充说明则按非限制性处理；随后检查标点和期刊语言习惯。
- **限制与例外**：原书承认限制性which/that的偏好不同，可受出版社规范约束；不能把所有which改为that，或把所有which前都加逗号。
- **来源**：第17章§17.7及Task 17.9答案；本书pp.136–137、212；PDF150–151、226。
