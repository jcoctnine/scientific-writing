### WS-001 降低读者理解成本，并通过重写澄清思想

**原书方法**：作者负责让读者容易理解；写作与思考相互推进，修改是写作的组成部分。

**适用情境**：稿件信息完整却难读，或作者尚不能清楚说明核心贡献。

**操作步骤**：定位读者必须自行补足的背景、推理或指代；补足必要连接；重写后检查观点是否更清楚。（提取者操作化。）

**限制与例外**：书中多次修订的次数是经验，不是固定流程；写作不能弥补根本薄弱的研究。

**来源**：第1章，书内5、7页／PDF 20、22；第21章§21.1，书内205页／PDF 220。

<a id="ws-002"></a>

### WS-002 从数据形成解释，再围绕问题组织叙述

**原书方法**：故事应由数据和可能解释生长出来；先自下而上探索，再自上而下讲清核心认识。

**适用情境**：手中已有多组结果，需要判断论文主线。

**操作步骤**：列出结果、异常与竞争解释；探索各解释能说明什么；再收束到由证据支持的主线。（依据原书过程重述。）

**限制与例外**：书内12页鼓励探索时大胆“过度解释”，其上下文是先发散再删减，不能视为成稿夸大结论的许可。

**来源**：第2章，书内9、11–12页／PDF 24、26–27。

<a id="ws-003"></a>

### WS-003 用四个问题检查全文是否闭合

**原书方法**：练习依次要求识别较大问题、具体问题或假说、关键结果和主要结论，并检查结论是否回答问题。

**适用情境**：起草前梳理材料，或检查全文是否存在问题与答案脱节。

**操作步骤**：分别用简短文字写出背景问题、研究问题、主要结果、结论；逐项检查结果如何支持答案。（由练习转化。）

**限制与例外**：原练习针对800–850词短文，限制结果为两三点；这些数量和字数不适用于所有论文。

**来源**：第2章练习2.2，书内14–15页／PDF 29–30。

<a id="ws-004"></a>

### WS-004 抓住简单核心，避免把复杂问题简单化

**原书方法**：简单是抓住问题的核心，不是删掉实质矛盾；可借助概念图、模型或紧凑说明检验理解。

**适用情境**：贡献表达分散、术语堆积或结论只有口号。

**操作步骤**：尝试用一句话或示意结构说清关键关系；检查被省略的信息是否改变解释。（提取者操作化。）

**限制与例外**：示意图是帮助作者理解的一种方法，不是所有论文的必需产物。

**来源**：第3章§3.1，书内17–18页／PDF 32–33。

<a id="ws-005"></a>

### WS-005 从读者已有知识引入新概念

**原书方法**：读者借助已有概念框架理解新内容；专业中层抽象需要用熟悉的概念或具体事实解释。

**适用情境**：跨领域写作、摘要或引言中出现专业概念。

**操作步骤**：判断目标读者已知什么；以已知概念引入对象；用必要的具体说明界定新概念。（依据原书重述。）

**限制与例外**：不必向专家重新讲解公认概念；类比和简化不能改变科学含义。

**来源**：第3章§3.1.1、§3.3，书内20–23页／PDF 35–38。

<a id="ws-006"></a>

### WS-006 用知识边界引发好奇，用证据维持可信度

**原书方法**：用已有知识界定未知，形成读者关心的问题；可信度来自既有研究、方法、数据及结论间的连续支持。

**适用情境**：重要性只靠形容词表达，或有新结果却说不出其知识贡献。

**操作步骤**：写清已知与尚未回答之处；说明答案的用途；逐环检查证据是否支持推论。（提取者操作化。）

**限制与例外**：书中SUCCES的“情绪”在科学写作中主要指好奇；不是要求戏剧化、煽情或承诺发表成功。

**来源**：第3章§3.2–3.6，书内21–25页／PDF 36–40。

<a id="ws-007"></a>

### WS-007 区分论证功能与IMRaD章节形式

**原书方法**：OCAR分别承担背景、挑战、行动和收束功能；这些功能可映射到IMRaD，但并不等同于四个实体章节。

**适用情境**：有章节标题却缺少研究问题或答案，或采用合并章节的稿件。

**操作步骤**：标出问题背景、具体挑战、研究行动及所得认识；检查它们在现有章节中的位置与联系。（提取者操作化。）

**限制与例外**：原书承认IMRaD的多种变体；不能据此强制更改期刊结构或段落数量。

**来源**：第4章§4.1–4.3，书内26–33页／PDF 41–48；Figure 4.2，书内33页／PDF 48。

<a id="ws-008"></a>

### WS-008 根据读者决定核心信息出现的早晚

**原书方法**：OCAR、ABDCE、LDR与LD的主要区别是问题和结论前置程度；作者把这种选择与读者耐心及阅读目的联系起来。

**适用情境**：同一工作面向专家与跨领域读者，或开头迟迟不出现重点。

**操作步骤**：确认读者需要先看推理过程还是先判断相关性；调整问题、概览和结论的位置。（提取者操作化。）

**限制与例外**：书中对Nature、Science等的概括属于作者写作经验，不是当前期刊规定；不把读者分成固定等级。

**来源**：第4章§4.1–4.2，书内27–32页／PDF 42–47。

<a id="ws-009"></a>

### WS-009 让开场准确设定问题、对象与读者预期

**原书方法**：开头应指出驱动研究的问题、核心对象和目标读者；常见失败是误导方向或没有方向。

**适用情境**：开头大而空、像教材，或第一段与后续研究重点不一致。

**操作步骤**：读完开头后预测论文要回答什么；与实际研究对照；删除无功能的背景或调整定位句。（提取者操作化。）

**限制与例外**：平实开场未必差；多步铺垫和直接切入均可，取决于读者与后续论证。

**来源**：第5章，书内35–36、38–39、47页／PDF 50–51、53–54、62。

<a id="ws-010"></a>

### WS-010 用逻辑漏斗说明小问题为何值得回答

**原书方法**：引言主体连接较大问题和具体问题；以知识边界逐步缩小范围，避免模糊的“研究很少”或先推销解决方案。

**适用情境**：研究意义与实验任务之间跳跃，或只宣传方法优势。

**操作步骤**：列出从较大问题到具体问题所需的推理节点；给每一步提供事实依据；将模糊缺口写成具体未知。（提取者操作化。）

**限制与例外**：不必从全球问题开篇；缺口可以小，但必须真实；无法证明的“首次”不能据此补写。

**来源**：第6章，书内50–51、53–57页／PDF 65–66、68–72。

<a id="ws-011"></a>

### WS-011 综合研究发现，按需要突出研究者

**原书方法**：引言引用用于界定知识边界；连续“某作者发现……”可能表示尚未综合。讨论争论或相反立场时，作者前置有其作用。

**适用情境**：相关工作成为按作者排序的流水账。

**操作步骤**：按发现、分歧或未决问题归组；选择信息前置或作者前置；保留对应引用。（依据原书重述。）

**限制与例外**：作者前置不是错误，不能全部机械改成括号引用；本节对综述的对照不代表所有综述只罗列知识。

**来源**：第6章§6.3，书内55–57页／PDF 70–72。

<a id="ws-012"></a>

### WS-012 区分研究问题、假说与操作目标

**原书方法**：问题说明想知道什么；假说是可检验的预测；目标交代获取信息的行动。不同学科不必同时写齐三者。

**适用情境**：引言结尾只列实验任务，或给探索性研究强加假说。

**操作步骤**：先明确知识问题；如适用，再列原有假说；说明回答问题的研究路径。（依据原书重述。）

**限制与例外**：是否需要假说或结果预告取决于研究与学科；不能把事后解释改称预设假说。

**来源**：第7章§7.1–7.4开头，书内58–60页／PDF 73–75。

<a id="ws-013"></a>

### WS-013 方法段先给目的与概览，再提供必要细节

**原书方法**：Methods服务于可信度判断和重复研究；先说明要获得的信息与方法概览，再给实验细节，常用方法可借助名称与引用。

**适用情境**：方法只有引用，或直接堆参数导致读者不明白用途。

**操作步骤**：写明测量/分析目的；交代具体方法及出处；说明关键参数和相对标准方法的变化。（依据原书重述。）

**限制与例外**：已知方法可简述，但不能以引用代替理解和复现所需的关键信息；并非每段都需增加目的套话。

**来源**：第8章§8.1，书内68–69页／PDF 83–84。

<a id="ws-014"></a>

### WS-014 区分数据、直接推断与更广解释

**原书方法**：结果可与讨论分开或合并，但读者必须分清实际发现、较直接的推断和更广的解释或假说。

**适用情境**：Results混入机制推测，或连续实验无法按纯结果/纯讨论分开讲清。

**操作步骤**：标记三类陈述；按研究推进逻辑组织；用措辞和位置使解释层级清楚。（提取者操作化。）

**限制与例外**：理论、模型和连续实验常需整合呈现；原书分类不自动决定某句话的科学可信度。

**来源**：第8章§8.2.1，书内70–71页／PDF 85–86。

<a id="ws-015"></a>

### WS-015 按论文问题选择正文结果，同时保留数据可用性

**原书方法**：不因数据来之不易就把所有细节放进主文；选取能推进论证的结果，其余数据可归档以供再利用。

**适用情境**：结果篇幅失控，正文成为实验记录清单。

**操作步骤**：说明各结果回答的具体问题；合并重复信息；判断哪些适合主文、补充材料或数据归档。（提取者操作化。）

**限制与例外**：叙事选择不能成为选择性报告的理由；书中出版与数据政策描述是历史背景。

**来源**：第8章§8.2.2末至§8.2.3，书内74页／PDF 89。

<a id="ws-016"></a>

### WS-016 先陈述结果模式，再用数值支持

**原书方法**：结果不应只有孤立数值；先给主要模式，再展开细节。作者同时强调效应大小与统计显著性不能混为一谈。

**适用情境**：逐项复述表格，或用“显著/不显著”替代结果本身。

**操作步骤**：明确方向、大小和研究条件；补充原有统计量；检查文字结论是否超出数据。（提取者操作化。）

**限制与例外**：书内78页把p=0.07解释为处理效应为真的概率超过90%，并据此推断可能为II类错误；已核对原页，属于原书问题。p值不是该后验概率，也不能由一个p值判定某次检验是否犯II类错误。

**来源**：第8章§8.2.3，书内74、78–79页／PDF 89、93–94。

<a id="ws-017"></a>

### WS-017 讨论可以从问题或主要发现展开

**原书方法**：Discussion回答研究问题、发展解释；可重申问题后逐步得出答案，也可先给主要发现再展开支持。

**适用情境**：讨论像结果重复，或开头结构不服务后续论证。

**操作步骤**：确定本节中心认识；选择问题引导或发现引导；检查展开段是否支持最终收束。（提取者操作化。）

**限制与例外**：原书明确反对把讨论写法公式化；不能要求所有论文都用同一首段模板。

**来源**：第8章§8.3，书内79–81页／PDF 94–96。

<a id="ws-018"></a>

### WS-018 结尾用研究答案回应开场问题

**原书方法**：有效收束从关键结果走向问题答案，再说明其对较大问题的贡献；单纯说“提供新见解”不等于说明新见解。

**适用情境**：结论重复结果或仅宣称重要。

**操作步骤**：概括必要结果；写出它回答了什么；说明有证据支持的贡献。（依据原书§9.3重述。）

**限制与例外**：不是必须扩展到更大范围。书中自身指出，推广至更大群体需要前文论据；不能用宽泛意义掩盖适用边界。

**来源**：第9章，书内83–84、88–90、92页／PDF 98–99、103–105、107。

<a id="ws-019"></a>

### WS-019 将未来问题写具体，避免空泛收尾

**原书方法**：新工作引出的具体问题可延伸贡献；空泛的“仍需进一步研究”不能替代结论。新主题若在结尾首次出现，应回头检查前文铺垫。

**适用情境**：结尾转向未讨论的新领域，或只剩未来工作套话。

**操作步骤**：区分尚未解决的原问题与本研究引出的新问题；写清未来验证对象；补足必要铺垫或移走无关句。（提取者操作化。）

**限制与例外**：不能为“有力结尾”删除影响解释的限制；不强制禁止最后一句提示不确定性。

**来源**：第9章§9.1–9.3，书内87、90–92页／PDF 102、105–107。

<a id="ws-020"></a>

### WS-020 让小节和段落形成完整论证单元

**原书方法**：全文由嵌套的较小论证单元构成；每个单元内部完整，单元之间顺序连接，避免同一论点分散出现。

**适用情境**：论述反复跳转，读者需要跨段拼接一个解释。

**操作步骤**：给每个单元写一句功能说明；将被拆散的同一论点归拢；检查单元起点、发展和结束。（提取者操作化。）

**限制与例外**：嵌套结构是分析工具，不要求每一句或每段显式具备四个标签。

**来源**：第10章，书内95–98、103页／PDF 110–113、118。

<a id="ws-021"></a>

### WS-021 按论证需要选择观点在前或在后

**原书方法**：常用段落先给观点再展开；需要整合证据得出结论时可把主要观点放在后部，结构之间也存在连续变化。

**适用情境**：段落无重点、过长或多条论证混在一起。

**操作步骤**：确定段落要读者理解的一点；决定先说还是逐步建立；拆开不相容的主题。（依据原书重述。）

**限制与例外**：不强制首句必须是主题句；书中的25–30%经验比例不是配额；有时需增加文字才能澄清关系。

**来源**：第11章，书内104–105、107–110页／PDF 119–120、122–125。

<a id="ws-022"></a>

### WS-022 利用句首主题与句末强调组织信息

**原书方法**：句首通常提供读者熟悉的主题，句末承载重要的新信息；位置改变读者对重点的理解。

**适用情境**：句子语法正确但重点埋没，或新术语突然出现在句首。

**操作步骤**：标出讨论对象和要强调的信息；重排后检查与前句联系及句末重点。（提取者操作化。）

**限制与例外**：这是英文信息结构的写作倾向，不能自动套用于每一句；术语放哪里取决于读者是否已知。

**来源**：第12章§12.1–12.3，书内113、115–116页／PDF 128、130–131。

<a id="ws-023"></a>

### WS-023 缩短主谓距离，移动限定语而不丢失含义

**原书方法**：长插入语会隔开主题和动作；冗长起句或句尾附带语可能埋没重点，移动或精简可改善可读性。

**适用情境**：长句主干难找，或限定语掩盖真正结果。

**操作步骤**：找到主语、谓语和重点；调整插入语；逐项检查限定语是否仍保持原作用范围。（提取者操作化。）

**限制与例外**：原书在“未观察到趋势”例中保留观察层面的不确定性；不能改成“趋势不存在”。

**来源**：第12章§12.4–12.5，书内116–119页／PDF 131–134。

<a id="ws-024"></a>

### WS-024 用概念承接形成衔接，先修结构再加连接

**原书方法**：连贯既需要同一主题，也需要新旧信息承接；可承接词或概念。若真正问题是论点混放，应先移句，而非勉强加衔接。

**适用情境**：句句通顺但段落跳跃，或连接词很多仍不连贯。

**操作步骤**：标出每句主题和重点；检查相邻句段的概念关系；先整理论证单元，再补必要承接。（依据原书重述。）

**限制与例外**：短的同主题列表可以有效，不要求每句都把前句末词放到句首。

**来源**：第13章，书内124–130、132页／PDF 139–145、147。

<a id="ws-025"></a>

### WS-025 按叙述对象选择主动或被动

**原书方法**：主动语态通常直接；被动语态可把受作用对象放到主题位置，或在施事不重要/不明确时使用。

**适用情境**：Methods或结果中语态僵硬，或改成主动后破坏段落主题。

**操作步骤**：确认本句讲谁、动作由谁完成；选择保持事实且与上下文衔接的语态。（提取者操作化。）

**限制与例外**：不把所有被动改成we；we可能错误地把协作者行为归给作者。需要明确责任时也不能借被动隐去主体。

**来源**：第14章§14.1，书内134–136页／PDF 149–151。

<a id="ws-026"></a>

### WS-026 用具体动作替代空泛动词和无用名词化

**原书方法**：空泛动词只说发生了事情而没说发生什么；把动作藏在名词里会增加长度。可将实际动作恢复为动词。

**适用情境**：conduct an investigation等表达冗长，或“影响/促进”掩盖已知关系。

**操作步骤**：找出真实动作；检查动词是否表达它；在含义不变时改写名词化和弱动词。（依据原书重述。）

**限制与例外**：不能在机制未知时擅自把“影响”换成确定机制；专业概念及回指需要的名词化可能应保留。

**来源**：第14章§14.2–14.3，书内138–142页／PDF 153–157；第18章回指例，书内188页／PDF 203。

<a id="ws-027"></a>

### WS-027 根据读者和精确性判断术语是否必要

**原书方法**：术语与行话的边界取决于读者及是否有准确的普通表达；同义词可能含义不同，选词需同时考虑可懂性和语义。

**适用情境**：语言过重，或为避免重复频繁更换关键概念名称。

**操作步骤**：判断读者是否理解；能准确简化则简化，否则解释术语；替换前检查含义和学科用法。（依据原书重述。）

**限制与例外**：不能按词源、词长或“口语常用”自动替换；死亡率、病死率等不同指标不能混同。

**来源**：第15章§15.1–15.3，书内146–147、149–153页／PDF 161–162、164–168。

<a id="ws-028"></a>

### WS-028 降低缩写与命名的记忆负担

**原书方法**：缩写初次出现通常需展开；命名应帮助读者辨识，而不只是方便作者。

**适用情境**：摘要/开头缩写密集，分组或模型代号难记。

**操作步骤**：检查缩写首次定义及后续用途；解释组名所代表的区别；减少无必要的自造代号。（提取者操作化。）

**限制与例外**：DNA等高度通用缩写未必需展开；原数据标签、正式术语及期刊要求不能随意重命名。

**来源**：第15章§15.1.2，书内149–150页／PDF 164–165。

<a id="ws-029"></a>

### WS-029 平衡名词组合的紧凑性与歧义

**原书方法**：简短名词组合常比介词短语紧凑；过长名词串则可能造成修饰关系不清，需要介词拆分。

**适用情境**：多重of短语冗长，或连续名词难以解析。

**操作步骤**：确认中心词与修饰关系；尝试紧凑组合或介词拆分；比较清晰度和句末强调。（依据原书重述。）

**限制与例外**：原书给出的名词数量是经验提示；已有稳定术语应按整体理解，不按个数强制拆分。

**来源**：第15章§15.4，书内153–156页／PDF 168–171。

<a id="ws-030"></a>

### WS-030 压缩先处理内容与结构，再删词

**原书方法**：先删无必要的内容块，整理重复或破碎的论证，再削减无用词语；靠字号和密排不能解决信息过载。

**适用情境**：全文超字数或同一观点反复出现。

**操作步骤**：标记各部分功能；移除或转移无关内容；合并重复论点；最后精简句子。（依据原书重述。）

**限制与例外**：书中的10%或20%为训练和个人经验，不能成为必须完成的删减率；限定与反证不是可优先删的“枝叶”。

**来源**：第16章§16.1，书内159–161页／PDF 174–176。

<a id="ws-031"></a>

### WS-031 区分冗余修饰与承载信息的限定语

**原书方法**：删除重复、显而易见的修饰和无用元话语；保留改变含义的修饰，以及帮助读者理解和衔接的文字。

**适用情境**：冗长句、宣传性形容词或压缩后难懂的文字。

**操作步骤**：逐项判断词语是否增加事实、范围或衔接；只删无功能部分；回读压缩后是否仍表达同样证据强度。（提取者操作化。）

**限制与例外**：“初步”“可能”“本样本中”等可能是必要信息；原书自己允许较完整初稿和为流畅保留额外文字。

**来源**：第16章§16.4–16.10，书内163、165–168、170–173页／PDF 178、180–183、185–188。

<a id="ws-032"></a>

### WS-032 按结构、清晰、衔接、语言循环修订

**原书方法**：SCFL依次关注Structure、Clarity、Flow、Language；各问题相互影响，修订可反复循环，朗读能发现视觉阅读漏掉的问题。

**适用情境**：稿件同时存在组织和语言问题。

**操作步骤**：先识别主要结构问题；再澄清概念、衔接和语言；改动后重新检查整体。（依据原书重述。）

**限制与例外**：不等于固定四轮，也不是必须无限打磨；局部修改不需要重启全部流程。

**来源**：第17章，书内174–175、178页／PDF 189–190、193。

<a id="ws-033"></a>

### WS-033 在读者需要时说明局限，并据此约束结论

**原书方法**：尽早解释影响理解的局限；技术细节可放Methods，解释限制放Discussion。作者偏好先限制再说明仍成立的认识。

**适用情境**：局限到文末才出现，导致读者重新解释前文。

**操作步骤**：说明限制影响什么；决定最早需要解释的位置；将结论限制在仍成立的范围内。（依据原书重述。）

**限制与例外**：书中明确承认新颖/不寻常方法的局限可放Discussion开头，结论中也可能必须提及。不可将“but, yes”变为隐藏风险或必然正向收尾。

**来源**：第18章，书内180–188页／PDF 195–203，尤其§18.3.1–18.3.2。

<a id="ws-034"></a>

### WS-034 让研究问题与方法实际可支持的答案一致

**原书方法**：有些问题出在提问范围超出方法能力；应清楚说明方法能提供哪种信息，而非作不可能兑现的承诺。

**适用情境**：测量的是代理指标，却在引言或结论中回答更宽的问题。

**操作步骤**：对照问题、测量对象与解释范围；标出不一致；据实际研究澄清表述。（提取者操作化。）

**限制与例外**：原书“没有坏方法”的说法是强调方法与用途匹配的修辞，不是有效性保证；也不能把事后改题伪装成预注册目的。

**来源**：第18章§18.1–18.2，书内181–184页／PDF 196–199。

<a id="ws-035"></a>

### WS-035 让贡献与目标读者匹配，先解决论证再润色

**原书方法**：国际读者需要理解工作带来什么认识；新地点或新技术本身未必构成知识创新。选择传播对象时应关注内容范围，而非仅看期刊地位。

**适用情境**：把“首次在某地”作为全部创新，或把论证问题归咎于英文不够华丽。

**操作步骤**：区分数据资源贡献、局部应用价值与可推广认识；说明目标读者为何需要；最后检查英文清晰和准确。（提取者操作化。）

**限制与例外**：这是作者面向高影响力研究的经验，不否定重复研究、描述性研究或本地应用价值，也不能据此预测接收结果。

**来源**：第19章，书内189–194页／PDF 204–209。
