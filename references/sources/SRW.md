## 全篇写作与可更新方法

<a id="srw-001"></a>

### SRW-001 逆向分析句子和段落的功能

**原书方法**：把成功发表文本当作可分析对象：先描述每句/每段“在做什么”，再寻找实现该功能的词汇、语法与组织方法，并用后续阅读持续调整模型。第二版明确采用描述性而非固定规定式的方法。

**适用情境**：建立某类科研正文的写作方法，或作者知道要写什么却不知道怎样组织时。

**操作步骤**：选择同研究主题、同体裁的近期范文；标注背景、缺口、方法理由、结果解释等功能；删除学科内容词以得到可迁移描述；在其他文本测试模型；归纳语言手段；用自己的真实材料完成相应功能。

**限制与例外**：原书建议至少四篇目标文章，并在部分章节用至少两篇练习建模；这是学习采样建议，不是验证充分性的统计标准。书中还建议来自英语机构/英语母语作者的范文，这是作者的选样建议，不能当成科学质量或写作质量的必要条件。

**来源**：前言与全书 Introduction，书内 ix–x、xvii–xviii、xxiii–xxiv（PDF 10–11、18–19、24–25）；1.2.1，书内 p.4（PDF 33）。

<a id="srw-002"></a>

### SRW-002 先确定读者与叙事方向，再组织信息

**原书方法**：论文不只是存放信息。作者须让读者知道信息的功能、与前文的关系和研究的主贡献，并通过分节、段落顺序、图表位置和句子入口建立叙事。

**适用情境**：材料很多、结构像实验笔记，或跨学科读者无法判断为何出现某项信息。

**操作步骤**：确定体裁与潜在读者；列出研究成就及对知识/研究/现实的贡献；按重要性排序；据此安排章节、段落、句子和图表；逐项检查是否服务于中心信息。

**限制与例外**：原书承认并非每项研究都有可识别的现实应用或影响。叙事应解释信息，不能替证据制造意义。

**来源**：全书 Introduction，书内 xiii–xvi（PDF 14–17）；8.1，书内 pp.314–317（PDF 343–346）。

<a id="srw-003"></a>

### SRW-003 区分起草、呈现与阅读的顺序

**原书方法**：书按 IMRaD 编排只是便于讲解。作者常先写 Methods，再 Results、Discussion/Conclusion、Introduction，最后 Abstract/Title；实际期刊可能后置 Methods，读者也常跳读。

**适用情境**：确定起草入口，或需要让摘要、结果、结论在跳读情况下可理解。

**操作步骤**：将写作进度与文章目录分开；从现有可靠材料最充分的章节推进；在全文稳定后检查摘要、题目及前后呼应；检查独立阅读的章节是否提供必要背景。

**限制与例外**：原书说的是常见做法，不是所有论文必须遵循的生产顺序，也不意味着每章重复完整背景。

**来源**：全书 Introduction，书内 xxii–xxiii（PDF 23–24）；6.1，书内 p.267（PDF 296）。

<a id="srw-004"></a>

### SRW-004 将 Introduction 四部模型当作可选功能菜单

**原书方法**：常见引言由领域意义/背景及总体问题，已有研究和贡献的地图，缺口/问题/动机/假设/机会，以及本研究介绍组成。作者明确说不必使用每项。

**适用情境**：引言缺少清晰推进路径，或需要检查研究为何值得开展。

**操作步骤**：标记现有段落的四类功能；检查从领域到本研究的连接；补充理解所需背景；在末段清楚呈现本研究，按需要简述目标、方法、结果或贡献。

**限制与例外**：研究只是延伸前人工作时缺口可不显式写出；背景可在任何必要位置补入；不是固定四段或固定句数。

**来源**：1.1–1.2.3，书内 pp.3–4、14–17（PDF 32–33、43–46）。

<a id="srw-005"></a>

### SRW-005 用共享背景帮助目标读者进入文章

**原书方法**：开头的信息层级由读者决定。宽泛或跨学科读者需要较一般的共同起点；狭窄共同体可能适合直接给特定事实、定义或研究焦点。

**适用情境**：首句过空泛、过技术化，或改投期刊导致读者变化。

**操作步骤**：判断读者可共享的知识；选择能引入核心概念的事实或领域意义；逐步过渡到特定问题；检查是否从一般信息突然跳到技术细节。

**限制与例外**：并非所有论文都要用“重要性”开头。原书建议必要时略多给背景，不能解读为引言越长越好。

**来源**：1.2.2，书内 pp.6–10（PDF 35–39）；1.6，书内 p.71（PDF 100）。

<a id="srw-006"></a>

### SRW-006 将文献回顾组织为通向研究问题的路线

**原书方法**：引言文献回顾不是已读论文清单；每项研究应必要且相关，说明领域如何发展到本研究的问题，并帮助读者识别研究在领域中的位置。

**适用情境**：引言逐篇“某某发现”罗列，或不同方法来回跳转。

**操作步骤**：从研究问题反向选择必要文献；按一般到具体、方法/理论分组，或适合题目的时间发展组织；说明研究之间是延伸、替代、支持还是未解决关系。

**限制与例外**：时间顺序在研究受政策、历史事件等驱动时可能合适，不应一律按年代排。引文位置应准确对应受支持的分句。

**来源**：1.2.2，书内 pp.11–14（PDF 40–43）。

<a id="srw-007"></a>

### SRW-007 从具体缺口自然转入本研究

**原书方法**：先描述领域总体问题，再指出本研究回应的具体知识缺口或既有研究问题；通常用尊重、非人身化的表述，随后直接介绍本研究。

**适用情境**：缺口含糊、研究目标突兀，或引言末段方法细节过多。

**操作步骤**：区分总体问题与本研究要回应的问题；说明已有知识哪里尚未满足需求；用连接语呈现转折；紧接本研究目标/方法概要及与缺口有关的贡献。

**限制与例外**：原书把“提问形式较少见”作为体裁观察，不等于禁止研究问题。方法和结果概要的详略依目标文章而定。

**来源**：1.2.2–1.2.3，书内 pp.14–17（PDF 43–46）。

<a id="srw-008"></a>

### SRW-008 按信息功能选择时态

**原书方法**：过去时通常把发现限定于某项研究；现在时常表达已接受事实或更一般的主张；现在完成时可突出既有工作对当前问题的相关性。时态变化具有意义。

**适用情境**：文献段落时态混乱，或润色把观察结果升级为普遍规律。

**操作步骤**：给每句标注已知背景、某项研究发现、当前缺口、本文内容等功能；据此选时态；检查切换是否改变证据归属或普适程度；必要时参照领域当前用法。

**限制与例外**：时态不是证据强度的独立证明。原书也指出某些模型/学科全文使用现在时；选择自身结论的强度不能只模仿他人，须依据自己的数据。

**来源**：1.5.1，书内 pp.53–55（PDF 82–84）；3.2.3，p.155（PDF 184）；4.2.2，pp.201–204（PDF 230–233）。

<a id="srw-009"></a>

### SRW-009 用准确衔接连接句间信息

**原书方法**：可通过重复关键词、this/these 加明确名词、适当分号和连接词衔接。连接词承担因果、对比、递进等具体关系，不是通用粘合剂。

**适用情境**：句子各自正确但跳跃、代词含糊，或 however/therefore 堆积。

**操作步骤**：检查后一开始是否承接已知信息；必要时重复同一术语；把模糊 this 改为 this result 等；逐一验证 therefore 的因果和 moreover 的同类递进关系；避免每句机械加信号词。

**限制与例外**：分号不能为节约句号无限加长句子；as、since、while 可兼表时间或逻辑关系，应避免双解。

**来源**：1.5.2，书内 pp.56–62（PDF 85–91）；8.2，pp.318–320（PDF 347–349）。

<a id="srw-010"></a>

### SRW-010 一个段落承担可识别的主要功能

**原书方法**：段落在视觉和认知上分隔概念；常由提示主题、目的或功能的入口句启动，其余句子围绕该功能发展。

**适用情境**：整页大段、许多单句段，或段落从一个概念漂移到另一个概念。

**操作步骤**：列主题并排序；列每个主题的要点；分配段落功能；写入口句；检查每句是否推进该功能；主题明显改变时另起段。

**限制与例外**：书中 150–170 词等平均长度是描述性参考，不是字数验收线；一个主题可能需要多个不同功能的段落。

**来源**：1.5.4，书内 pp.65–68（PDF 94–97）；8.1，p.317（PDF 346）。

<a id="srw-011"></a>

### SRW-011 语态与主语选择服务于归属和可读性

**原书方法**：作者可以用 we/our、被动语态或 This study 等非人主语；选择涉及期刊惯例、表达重点和歧义。we 的指代不应在作者群体、整个领域和所有人之间悄然切换。

**适用情境**：不清楚某句话指作者做了什么、他人做了什么，还是一般知识。

**操作步骤**：识别动作实施者和信息拥有者；稳定 we 的指代；必要时写 in this study/in their model、引文或明确主语；再选择语态。

**限制与例外**：主动不自动清楚，被动也非一律不当；本书承认一些流程通常仍用被动。非人主语若隐藏作者贡献，也需补归属标记。

**来源**：1.5.3，书内 pp.64–65（PDF 93–94）；2.5.1，pp.113–115（PDF 142–144）；8.3，pp.321–322（PDF 350–351）。

<a id="srw-012"></a>

### SRW-012 Methods 是供他人理解和复现的说明

**原书方法**：方法不是实验记录照搬；要给读者足够细节以重复工作并获得相似结果。六类功能包括概览/来源、操作细节、图表内容、与已有方法关系、必要背景、问题或局限。

**适用情境**：从实验笔记写 Methods，或方法细节分散于正文和补充材料。

**操作步骤**：先安排小节和总体流程；给材料/设备来源；描述操作细节；按理解需要加入背景、图示、理由和已有方法；核对补充材料能被准确定位。

**限制与例外**：模型是菜单，未遇到问题不必捏造“问题项”；专业共同体读者已熟悉方法时可直接切入。Methods 后置/外置时正文仍应提供理解结果所需信息。

**来源**：2.1–2.2.3，书内 pp.75–88（PDF 104–117）；2.6，pp.127、136–137（PDF 156、165–166）。

<a id="srw-013"></a>

### SRW-013 报告选择理由及真实的质量控制

**原书方法**：方法应说明做了什么，以及为何如此选择；材料性质、设备能力、程序目的和适当的操作细节帮助读者接受方法。

**适用情境**：方法只有动作清单，读者无法判断参数、地点、材料或技术的理由。

**操作步骤**：找出关键选择；写其目的或相关性质；补充理解该选择所需的事实/文献；准确陈述采样、处理、保存、检测过程中实际采取的控制措施。

**限制与例外**：原书用 tightly、directly、separate 等展示“操作谨慎”的修辞效果；这些词必须对应真实操作，不能用形容词代替验证。

**来源**：2.2.2，书内 pp.79–85（PDF 108–114）；2.4.2，pp.107–109（PDF 136–138）。

<a id="srw-014"></a>

### SRW-014 精确区分顺序、时间与空间关系

**原书方法**：then/next 只表示先后，不能充分说明持续时间、间隔、同时发生或步骤交接；空间方位、对象和操作动词也影响复现。

**适用情境**：实验、模拟或采样流程能读懂但无法照做，或结果变化的时间关系含糊。

**操作步骤**：检查每步的动作、对象、参数和时长；说明何时开始/结束、是否同步及触发条件；用明确的方位词描述装置关系；区分时间先后和因果。

**限制与例外**：具体时长和参数只能来自记录；“同时发生”不能被编辑成因果。书中八类时序词是语义分类，不要求逐类使用。

**来源**：2.2.2，书内 p.82（PDF 111）；2.4.2，pp.100–105（PDF 129–134）。

<a id="srw-015"></a>

### SRW-015 清楚区分沿用、改用和原创的方法部分

**原书方法**：已有方法可简述并引用；即使文献可查，也不应迫使读者离开本文才能理解核心流程。相同、近似和明显不同的方法关系要表述清楚，重大改动应具体说明。

**适用情境**：一段混合标准流程与作者改动，或引文置于句末造成原创部分误归他人。

**操作步骤**：标识采用的已有部分；给恰当引文和必要简述；列出实际修改及原因；把引文放到其支持的内容处；核对每句动作的归属。

**限制与例外**：书中描述常识化后引文可能减少，但不能仅以“很多人都这么写”为由替作者删除必要归属；相似措辞不证明方法完全相同。

**来源**：2.2.2，书内 pp.83–85（PDF 112–114）；2.4.2，pp.109–110（PDF 138–139）；2.5.1，pp.113–115（PDF 142–144）。

<a id="srw-016"></a>

### SRW-016 在问题发生处报告限制，再接未来工作

**原书方法**：应让读者看到作者知道方法或结果的困难；通常在发生位置首次交代，再在 Discussion/Conclusion 回访。书中还列出弱化问题/责任、突出积极面和提出解决办法的修辞策略。

**适用情境**：限制首次在文末突然出现，或方法问题完全未交代。

**操作步骤**：指出实际问题及发生环节；说明已知影响与处理；将未解决部分连到后续可检验工作；分别表达已实施缓解与尚未验证的建议。

**限制与例外**：原书“弱化问题/责任”不能无条件转为技能要求。本次转化边界：只有证据支持时才称影响小；不淡化失效风险、不隐藏负面或不一致结果。

**来源**：2.2.2，书内 pp.85–86（PDF 114–115）；2.4.2，pp.111–112（PDF 140–141）；3.2.2，pp.152–153（PDF 181–182）。

<a id="srw-017"></a>

### SRW-017 将介词承载的关系写清楚

**原书方法**：介词会改变动作方向、因果、工具和位置；with、from 等可多解，串联介词短语会造成修饰附着不清。可观察领域动词搭配，并在必要时改成明确词组。

**适用情境**：一句包含多组 of/in/with/for，或不清楚使用什么工具、替换方向和改进幅度。

**操作步骤**：确认 intended meaning；对 substituted for/with、results in/from 等检查方向；用 using、as a result of 等澄清歧义；拆开附着关系不清的长串短语。

**限制与例外**：不是删掉所有介词。原书的搭配例句是局部语境，不能机械套到另一专业含义。

**来源**：2.5.2，书内 pp.115–120（PDF 144–149）；8.3，pp.322–323（PDF 351–352）。

<a id="srw-018"></a>

### SRW-018 用冠词表达共享知识与唯一性

**原书方法**：a/an、零冠词和 the 不仅是语法问题，也区分首次引入、一般类别、读者已知对象和唯一指代；a cause 与 the cause 可能改变论断。

**适用情境**：两种冠词在语法上都成立，却可能改变材料范围、对象数量或因果唯一性。

**操作步骤**：判断名词在当前专业语境的可数性；检查对象是否已引入或唯一；从读者可知范围选择冠词；复核修改是否把一种原因写成唯一原因。

**限制与例外**：可数性依语境，某些材料名称可被专业作者用复数表示类型；不能单凭词表断定所有用法。

**来源**：2.5.3，书内 pp.121–126（PDF 150–155）；3.5，p.184（PDF 213）；8.3，p.322（PDF 351）。

<a id="srw-019"></a>

### SRW-019 按论证需要与期刊惯例安排 Results/Discussion

**原书方法**：结果、讨论、结论可分开或合并。若早期结果决定后续步骤，或有多组假设，按组呈现结果和讨论可能更易理解；若要整体解释，可先集中报告结果。

**适用情境**：规划论文后半部结构。

**操作步骤**：识别各结果间的依赖与研究问题；检查目标体裁允许的结构；选择分组或整体解释方式；小节标题准确反映内容与功能。

**限制与例外**：书将三者分章是为了教学，不是在要求所有投稿都拆成三个独立章节。不能凭通用规则否定目标期刊结构。

**来源**：3.1，书内 p.141（PDF 170）；3.2.3，p.156（PDF 185）；5，p.245（PDF 274）。

<a id="srw-020"></a>

### SRW-020 Results 需要可进入、可追踪的叙事

**原书方法**：结果章节不是按实验发生顺序列数字；可先回顾目标、关键方法、相关文献或总体趋势，帮助读者形成框架。独立跳读和 Methods 外置会增加必要方法回顾的需求。

**适用情境**：结果开篇突兀、顺序像日志，或读者看数字却不知回答什么问题。

**操作步骤**：确定每组结果服务的目标；按依赖关系和读者理解安排次序；给必要入口/概览；分组时用过渡语；检查每组结果与原研究问题的关系。

**限制与例外**：原书建议必要时重审引言目标措辞；转化时不能用此理由追溯性改写预注册问题或隐瞒探索性分析。

**来源**：3.2.1–3.2.2，书内 pp.142–146（PDF 171–175）；3.5，pp.186–187（PDF 215–216）。

<a id="srw-021"></a>

### SRW-021 文字为图表提供阅读路径

**原书方法**：图表不能替代全部 Results 文字。图表的顺序、放置位置和前后解说影响读者理解；重点结果需要更多解释，不能把图中所有数据等权重复。

**适用情境**：正文仅写“见图”，或把整张表逐项重述。

**操作步骤**：明确每图回答的问题；确定读者在哪一步需要看它；在正文指出关键模式、比较或异常；给必要数值与范围；由图表及解说引向下一结果。

**限制与例外**：原书提到最佳结果常被写成典型结果，这是对写作做法的观察，不应转为选择性报告规则。主要结论应反映整体证据，不能以“例如”掩盖代表性问题。

**来源**：3.2.2，书内 pp.146–151（PDF 175–180）；3.4，p.170（PDF 199）。

<a id="srw-022"></a>

### SRW-022 评价数字时交代参照与尺度

**原书方法**：裸数字没有自动明确的意义；作者可用相似、差异、仅、达到等语言说明其在研究中的意义，并与文献、预测、模型或其他结果比较。

**适用情境**：读者无法判断比例高低、差异大小及何者重要。

**操作步骤**：确定评价对象与比较基准；描述方向与程度；保留支持该评价的数字；区分“实际重要”“令人意外”和统计检验意义。

**限制与例外**：原书的 only/as many as 和 striking 展示修辞作用，不为形容词本身提供数据依据；本次不把它们默认加入所有结果，也不将 significant 自动视为统计显著。

**来源**：3.2.2，书内 pp.147–151（PDF 176–180）；4.4，pp.224–225（PDF 253–254）；8.1，p.316（PDF 345）。

<a id="srw-023"></a>

### SRW-023 区分结果的直接解释和更广含义

**原书方法**：Results 可包含比较、必要背景、对数据如何/为何出现的直接解释，以及简短含义；广泛讨论通常留给 Discussion。结果的局限在相应位置报告。

**适用情境**：“Results 完全不能解释”与“结果段写成讨论”之间的边界判断。

**操作步骤**：标出每句是数据、直接解释、局限还是外推；保留读懂结果必需的解释；将较广的理论/应用推论放到合适位置；结尾可用受证据限制的含义引向讨论。

**限制与例外**：具体边界随期刊与结构变化；不得将模型预测、观察和推测混写成同等证据。

**来源**：3.2.2–3.2.3，书内 pp.151–155（PDF 180–184）。

<a id="srw-024"></a>

### SRW-024 将主张放到有证据支持的确定性层级

**原书方法**：从推测到证明存在连续谱；因果动词、时态、数量/频率限定和情态词共同传达确定性。linked to/associated with 不必意味着因果，更不指定因果方向。

**适用情境**：相关被写成因果、部分被写成全部，或谨慎程度与数据不匹配。

**操作步骤**：确认数据支持的是关联、部分解释、因果或应用可能；选择准确动词；保留适用人群/条件和频率限定；复核时态与情态是否进一步扩大主张。

**限制与例外**：个人确信不等于实验证明；也不应不加判断地层层套 may/might 而削弱已被充分支持的结论。

**来源**：3.5，书内 pp.183–186（PDF 212–215）；4.2.2，pp.202–204（PDF 231–233）；8.4，p.329（PDF 358）。

<a id="srw-025"></a>

### SRW-025 先确定 Discussion 要带走的贡献

**原书方法**：讨论前先退一步确定研究主要价值：可能是更合适的方法、结果本身、对知识/研究方向的影响，或应用。清楚的终点帮助组织从结果到结论的叙事。

**适用情境**：Discussion 信息很多但主线不清。

**操作步骤**：区分研究“完成了什么”与“对外改变了什么”；选主贡献；据此决定开头直接陈述贡献，还是回访缺口、方法、背景或关键结果；安排其后论证。

**限制与例外**：原书认可贡献可在开头、结尾或贯穿讨论；不是必须以“首次”“最大”开头，也不是每项研究都应宣称改变领域。

**来源**：4.1–4.2.3，书内 pp.191–198、207–208（PDF 220–227、236–237）。

<a id="srw-026"></a>

### SRW-026 回答引言问题，并把贡献放回既有知识

**原书方法**：Introduction 从领域与文献收束到缺口和研究；Discussion 反向展开，说明回应缺口的程度、与已有研究的关系及对领域的贡献。

**适用情境**：讨论只是重复结果，或引文与本研究结论没有明确关系。

**操作步骤**：逐个回应引言中的目标/假设；与相关已有研究比较；写清确认、扩展、冲突或新边界；用相关引文支持关系并明确其具体作用。

**限制与例外**：这是一种功能对应，不是把引言倒序复制。讨论可首次引用与解释/应用直接相关的文献；引用数量均值仅用于观察惯例。

**来源**：4.2.1–4.2.2，书内 pp.192–193、198–201（PDF 221–222、227–230）；4.4，pp.221、223–224（PDF 250、252–253）。

<a id="srw-027"></a>

### SRW-027 重访关键结果是解释的起点，不是终点

**原书方法**：Discussion 可以且通常需要概述结果以支持含义，但仅重复或换词不够；需说明这些结果在已有知识和研究问题中的意义。

**适用情境**：作者误以为讨论不能提结果，或讨论完全重述 Results。

**操作步骤**：选与主贡献相关的结果；简短回访；接其解释、与知识的关系及适用边界；必要时保留同一术语产生回响，不为文风而换概念。

**限制与例外**：解释与外推的强度必须由结果和既有知识支撑；原书明确要求既不夸大也不无故低估。

**来源**：4.2.2，书内 pp.202–205（PDF 231–234）；4.4，p.221（PDF 250）。

<a id="srw-028"></a>

### SRW-028 从具体限制提出具体后续研究

**原书方法**：有根据、明确的后续问题比泛称“还需研究”更有用；应用可在讨论早期或末尾出现。future work should 是建议，future work will/underway 通常指作者计划或已在进行的工作。

**适用情境**：展望空泛，或建议被写成已承诺开展的研究。

**操作步骤**：找未解决的问题或结论边界；说明下一步需考察的对象/比较；标注这是建议、已定计划还是进行中；有应用时说明它从何结果而来。

**限制与例外**：并非所有研究有实际应用。原书允许未被正式采集的线索或结论尚需验证的限制首次在讨论出现；不能把这类线索写成正式结果。

**来源**：4.2.2，书内 pp.204–206（PDF 233–235）；2.4.2，p.111（PDF 140）；4.4，p.226（PDF 255）。

<a id="srw-029"></a>

### SRW-029 按功能辨别情态动词，必要时改成明说

**原书方法**：can/could、may/might、should、must 等可表示能力、可能、预期、建议、必要或推断；同一词可多义，否定形式也可能改变含义。

**适用情境**：论文的能力、预测与建议混淆，或 may not 被改成 cannot。

**操作步骤**：先用普通语义改述“能够/可能/预计/建议/必须/推断”；再选择对应形式；核对时间和否定范围；存在双解时改为 is able to、is expected to、it is possible 等。

**限制与例外**：must 的推断性确信不等于有直接证据；should 可能是建议也可能是预期；may not 与 cannot 不等价。书中细微强弱排序属于语境性教学，不宜硬编码为概率值。

**来源**：4.5，书内 pp.229–241（PDF 258–270），特别 pp.231–239；否定表 p.234（PDF 263）已核页。

<a id="srw-030"></a>

### SRW-030 Conclusion 聚焦研究产出和影响

**原书方法**：结论可独立成节，也可为讨论末尾一两段；其功能是给清楚的核心信息，超过重复或摘要。可按需要选择研究成果、关键结果、含义、限制、应用与未来方向等成分。

**适用情境**：结论照搬 Abstract，或结尾罗列了所有步骤却缺少核心产出。

**操作步骤**：确定本研究的关键产出；用最必要的结果支撑；说明知识贡献和适用边界；按需要接真实应用或后续问题；与标题和引言承诺核对。

**限制与例外**：书中 11 项是可分析成分，不是每份结论必须有 11 句；100–200 词等平均值不是通用上限，长 Conclusion 有时兼具 Discussion 功能。

**来源**：Unit 5、5.1–5.3，书内 pp.245–246、257–258（PDF 274–275、286–287）。

<a id="srw-031"></a>

### SRW-031 让跳读结论的人识别哪些是本研究贡献

**原书方法**：结论中现在时与非人主语可能让本研究发现看似已有常识；用适当时态、主动语态、作者主语或明确研究指向可减少贡献归属歧义。

**适用情境**：单独读 Conclusion 时不清楚发现是本文所得还是文献背景。

**操作步骤**：将结论单独读一遍；圈出无法判定归属的陈述；用 this study、here、our results 或准确时态澄清；保持每项主张与证据一致。

**限制与例外**：过去时/现在完成时只是可用方式，不是必须把结论全部变成过去时；过度重复“we”也不必然更清楚。

**来源**：5.4，书内 pp.259–262（PDF 288–291）。

<a id="srw-032"></a>

### SRW-032 摘要优先传达主贡献，而非压缩一切

**原书方法**：摘要是独立文本，读者可能只看摘要。篇幅上限不是要填满的目标；应优先主要贡献，选择必要背景、方法、关键结果与含义，并通常在正文稳定后形成。

**适用情境**：摘要细节过多、中心模糊或与最新版正文不同。

**操作步骤**：确定读者需要知道的主贡献；从正文选必要内容；交代识别研究类型所需的方法信息；突出关键结果；最后核查正文一致性与字数要求。

**限制与例外**：不能因吸引读者而提高结论强度；摘要中的潜在应用也要保留限制。引文通常少见，但直接响应特定理论/研究时原书允许例外，最终应遵守投稿要求。

**来源**：6.1、6.3，书内 pp.265–268、286–288（PDF 294–297、315–317）。

<a id="srw-033"></a>

### SRW-033 在摘要字数限制下保留叙事与归属

**原书方法**：摘要仍需清楚指代、稳定术语和句间连接；可在一句中组合研究内容与成果、方法与结果、结果与含义等功能，不能为删字而牺牲可理解性。

**适用情境**：摘要被剪成无关系的短句，或名词换来换去造成读者误认多个对象。

**操作步骤**：清楚区分已有背景与本文贡献；固定核心对象名称；消解 it/this/which 歧义；合并相容的句子功能；定义确需使用的缩写；检查每次压缩是否改变关系。

**限制与例外**：组合功能不等于构造很长的多从句句子；缩写节字的收益须与潜在读者理解成本权衡。

**来源**：6.1、6.3.1，书内 pp.266–268、289（PDF 295–297、318）；6.5，p.297（PDF 326）。

<a id="srw-034"></a>

### SRW-034 区分摘要、意义声明、亮点和图文摘要

**原书方法**：书中分别讨论普通摘要、结构式摘要、带 Significance/Highlights 的摘要以及 Graphical Abstract。意义声明/亮点有不同呈现位置；图文摘要以易理解的主信息减少杂乱。

**适用情境**：为同一研究生成不同入口文本，避免一份摘要机械复制到所有字段。

**操作步骤**：确认所需文本/图像类型；分析各自功能与读者；为结构式摘要分配标题对应内容；让意义声明或亮点凸显中心贡献；图文摘要突出一条清晰信息并减少无关元素。

**限制与例外**：原书对图文摘要的“通常单幅”是观察，不是禁止多面板；这些输出并非所有投稿都要求，本阶段也不制作图像。

**来源**：6.2，书内 pp.269、276–282（PDF 298、305–311）；6.3，p.286（PDF 315）。

<a id="srw-035"></a>

### SRW-035 将工作题目改成准确表达最终产出的标题

**原书方法**：工作题目常只反映研究活动或研究对象；最终题目应让正确读者知道读完能得到什么，如一个工具、分析、方法或重要发现。

**适用情境**：题目仍是“某某研究/调查”，研究完成后却未更新。

**操作步骤**：从完成的结果和讨论确定贡献；识别读者所得；选择能表达对象与产出的题目；最后与 Conclusion 核查。

**限制与例外**：标题须由实际成果决定；不能因为“更吸引人”把探索性研究写成确定发现。

**来源**：Unit 7，书内 pp.301–303（PDF 330–332）。

<a id="srw-036"></a>

### SRW-036 从真实标题观察结构，避免固定长度模板

**原书方法**：可观察目标文章标题的长度、句子式或短语式、冒号的用途、方法/目的/应用成分，以及怎样表达贡献。平均长度仅是复杂度参照。

**适用情境**：决定题目形式或缩短冗长标题。

**操作步骤**：分析可比标题；区分冒号是在连接主题与焦点还是术语与定义；决定必要内容成分；检查句子式标题是否被目标领域接受；按内容而非平均数调整长度。

**限制与例外**：原书约 12 词等数值不构成限制；现在时发现句在部分期刊常见，也允许有根据的 may 等限定。

**来源**：7.1、7.5 及章前说明，书内 pp.302–304、309（PDF 331–333、338）。

<a id="srw-037"></a>

### SRW-037 让标题、关键词和缩写共同服务可发现性

**原书方法**：标题应吸引正确读者；关键词表可补充标题的更广或更专门概念，并减少标题过载。缩写在小共同体可能可用，但可能阻挡跨学科读者。

**适用情境**：标题名词堆积、关键词完全重复标题，或缩写只有组内人认识。

**操作步骤**：识别目前和潜在读者；判断缩写熟悉度；把次要但有检索价值的概念移到关键词；核对标题与关键词组合是否指向正确主题与读者。

**限制与例外**：书中建议用搜索结果检验题目/关键词；本次未执行检索。关键词与标题的重复不宜机械禁止，须兼顾期刊要求与核心检索词。

**来源**：Unit 7、7.2–7.3，书内 pp.301、305–306（PDF 330、334–335）。

<a id="srw-038"></a>

### SRW-038 审查标题的语法关系与承诺

**原书方法**：过长的复合名词、介词链可能模糊词间关系。标题暗示的焦点、结果及贡献必须在正文兑现，必要时用情态词保留可能性。

**适用情境**：标题每个词都对，但不清楚谁影响谁、改进了什么或适用于谁。

**操作步骤**：展开复合名词的关系；澄清介词；删除或转移次要项；读题目预测会得到什么，再与结论比较；检查是否夸大证据。

**限制与例外**：“明确”不能通过改写关系来实现；原材料不能判定方向时需作者澄清。

**来源**：7.4、7.6，书内 pp.307–310（PDF 336–339）。

<a id="srw-039"></a>

### SRW-039 控制句子的信息密度，不只数词

**原书方法**：读眼速度应与理解速度匹配；连续长句、多个 and/which、名词和介词聚集会隐藏主要动词和重点，也增加附着歧义。

**适用情境**：句子语法成立但需反复读，或压缩使信息过密。

**操作步骤**：找主要主语/动作；检查并列范围和修饰依赖；拆分不同命题；让已知信息引入新信息；在拆句后重新连接。

**限制与例外**：书中平均句长与读者理解百分比是书内说法，本次未独立核实其经验依据，不作为硬性阈值或效果保证。

**来源**：1.5.2，书内 p.58（PDF 87）；1.6，p.71（PDF 100）；8.2，pp.318–320（PDF 347–349）。

<a id="srw-040"></a>

### SRW-040 审查代词、修饰位置和 -ing 的真实指向

**原书方法**：it/which/this 可能指向多个成分；-ing 形式本身不显示时态或单复数，既可能模糊动作主体，也可能隐藏原因、时间、手段或结果关系。

**适用情境**：某从句似乎能修饰两个对象，或现在分词不能确定表示“通过”还是“从而”。

**操作步骤**：列出可能先行项/施事者；必要时重复准确名词；将 -ing 展开为真实的 by/when/because/which 等关系；复核主语能否在逻辑上执行动作。

**限制与例外**：不是禁止 -ing 或所有代词。若关系无法由上下文确定，不能自选一种关系当作事实。

**来源**：1.5.2，书内 p.58（PDF 87）；8.3，pp.323–325（PDF 352–354）。

<a id="srw-041"></a>

### SRW-041 将 only 等限定词放到正确作用对象旁

**原书方法**：only、just、simply 等的语序位置可改变句子的焦点和范围。对作者、动作、对象、模型能力或某一参数的限定不是同一个命题。

**适用情境**：限制词被润色移动后改变研究范围或排他性。

**操作步骤**：先用中文/明确说明写出要排除的内容；再检查限定词修饰哪一成分；必要时调整语序或拆句；核对数字和单位复合词的连接范围。

**限制与例外**：原书 only 对照表示范的是语义范围，不证明任何读者都只会按单一读法理解原句；应以消歧为目的。

**来源**：8.3，书内 pp.323–324、327（PDF 352–353、356）；p.324 表已核页。

<a id="srw-042"></a>

### SRW-042 稳定术语，选择准确而非华丽的词

**原书方法**：反复用同一核心术语有助读者追踪概念；把 tool 换成 strategy/device/framework 未必是风格改善。过于宽泛的动词也可能不如准确动作清楚。

**适用情境**：为避免重复频繁换术语，或 get/have 等掩盖具体关系。

**操作步骤**：建立对象的稳定名称；检查每次换词是否真有概念变化；选择与实际动作相符的动词；注意 include 与完整组成、adapt/adopt、imply/infer 等区别；必要时核查近期专业用法。

**限制与例外**：不等于禁止所有同义表达，也不要求僵硬重复每个普通词。书内词对解释常是教学简化，实际术语含义要由领域语境核定。

**来源**：全书 Introduction，书内 xxi（PDF 22）；6.1，p.266（PDF 295）；8.3，pp.326–328（PDF 355–357）。

<a id="srw-043"></a>

### SRW-043 用功能、归属和个人习惯进行末轮审读

**原书方法**：检查每句为何存在、谁在发言、引文支持何处及确定性是否合适；也检查反复出现的语气词、括号、破折号和逗号是否妨碍理解。

**适用情境**：结构已经稳定后的末轮修改。

**操作步骤**：独立读摘要/结论并检查贡献；通读段首获取逻辑地图；核对引文与分句；检查习惯性词语和插入语；必要时把括号/破折号隐含关系写明或拆成连接清楚的句子。

**限制与例外**：原书不是要求删除所有括号、破折号或 clearly；只修复没有功能、扰乱层次或导致歧义的使用。

**来源**：8.1–8.4，书内 pp.314–330（PDF 343–359），特别 pp.329–330（PDF 358–359）；1.5.4，p.67（PDF 96）。
